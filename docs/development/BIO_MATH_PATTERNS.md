# 生物・数式・フラクタルの生成ノード（開発中）

2026-11-27 JST。作業ブランチ `feat/bio-math-patterns`。基準は SolidCraft 統合 PR #48 の `7e7510b8118375d1e97a0237edc0c696626232a3`。PR #50 の標準ノード追加とは別の追加機能。既存の生成デザイン調査 [GENERATIVE_DESIGN_REFERENCES.md](GENERATIVE_DESIGN_REFERENCES.md) の葉序・フラクタル・周期曲線・成長パターンを具体化する。

## 目的と範囲

- `Phyllotaxis`：黄金角の葉序。黄金角の点配置。間隔×平方根の半径で円盤状、1点ごとの高さで立体らせんにします。
- `FibonacciSphere`：フィボナッチ球面。球面に面積の偏りが少ない決定的な点群を配置します。極は含みません。
- `RoseCurve`：バラ曲線。整数kの極座標 r=R cos(kθ) を閉じた折れ線にします。奇数kはk枚、偶数kは2k枚の花弁。
- `SuperformulaCurve`：スーパーフォーミュラ。Gielisの2次元式を正の指数と対称性で制御し、閉じた折れ線を生成します。a=b=1、mは4の倍数。
- `TorusKnot`：トーラス結び目。互いに素なp,qでトーラス上の閉じた結び目を折れ線生成します。小半径は大半径未満。
- `Lissajous3d`：リサージュ 3D。X/Y/Zの整数周波数と位相差で周期的な3D折れ線を生成します。自己交差する場合があります。
- `HilbertCurve`：ヒルベルト曲線。正方形を埋めるヒルベルト曲線の有限段階を開いた折れ線で生成します。
- `KochSnowflake`：コッホ雪片。正三角形の辺を外向きに4分割する再帰を行い、閉じた折れ線を生成します。
- `SierpinskiCells`：シェルピンスキー三角形。正三角形の中央を抜く再帰で残ったセルを、個別の閉じた輪郭として返します。
- `ReactionDiffusion`：反応拡散パターン。Gray-Scottモデルを周期境界の格子で有限回反復し、B濃度が閾値以上の点を返します。近似計算。
- `PoissonDisk2d`：最小間隔ランダム点。長方形内で最小距離を守る決定的な拒否サンプリング。試行上限で目標数より少なくなる場合があります。

- 既存の点・曲線型を使用。折れ線の数学的な標本であり、厳密NURBS、物理シミュレーション、Grasshopper標準コンポーネントとの互換性は宣言しない。
- 新しい「生成デザイン」カテゴリ。日本語名と英語キーワード、既存のItemアクセス、保存形式のsnake_case ID、出力数・重みの事前見積もりを使用。
- 点数は最大4096、周期曲線は最大2048標本、ヒルベルト6段、コッホ5段、シェルピンスキー6段。反応拡散は64×64格子・200反復、ポアソンディスクは512点・8192試行まで。
- スーパーフォーミュラは a=b=1、角度係数m=4×対称数。リサージュ・バラ曲線・結び目は標本の曲線で、自己交差を除去しない。ポアソンディスクは拒否サンプリングで目標数未満も許す。
- Gray-Scottは D_A=1、D_B=0.5、刻み0.2、単位格子の4近傍ラプラシアン、周期境界、濃度を[0,1]に制限した陽的Euler近似。実際の生物成長の予測ではない。
- 新規依存なし。Rustのみ。元の機能やフォーマットは変更しない。
