# Numerical contracts and regression evidence

This records the scope of the Omega geometry branch, not a claim of complete
Grasshopper compatibility. All algorithms are independently implemented. No
new numerical dependency or commercial CAD SDK is required.

## Finite binary64 sums and arithmetic means

`src/number_aggregates.rs` is the shared implementation for `Summation` and
`Average`. `MassAddition` calls `Summation`, so it has the same numeric behavior.
Each finite input is accumulated exactly; the final sum, or exact sum divided
by the item count, is rounded once to binary64, nearest with ties to even.

Every finite binary64 number is an integer multiple of 2^-1074. Positive and
negative magnitudes are accumulated separately in 34 little-endian 64-bit
limbs, then subtracted. A single maximum input needs 2098 bits; adding even the
maximum possible number of elements in a 64-bit Rust slice needs fewer than
2163 bits. The two fixed arrays provide 2176 bits each. The accumulator itself
uses fixed stack space; the existing node input conversion still allocates a
bounded numeric list.

For a mean, integer long division retains a remainder. Rounding considers the
guard bit, all remaining low bits, that remainder and the parity of the final
significand. This avoids both scaling small values to zero before cancellation
and rounding a sum before dividing it. A sum slightly larger than `f64::MAX`
can still round to `MAX`; overflow is rejected only when the rounded answer
would be infinite. Exact cancellation returns `+0`; a negative nonzero mean
that underflows can return `-0`.

Existing list contracts remain: empty sum is zero, empty mean produces no item,
nonfinite inputs are errors, and cancellation is checked while accumulating.
Population variance, standard deviation, matrix products and Fourier nodes
have their own algorithms; this change does not make them exact accumulators.

### Independent answers

`tests/sum_rounding_regressions.rs` covers cancellation down to the smallest
subnormal, overflow boundaries, subnormal/normal ties, signed underflow,
integer-limb boundaries and division remainders. The checked-in 128-case
fixture is generated by `scripts/generate_sum_oracle.py` with Python
`fractions.Fraction`, using exact represented inputs and one final conversion.
Both original and reversed input orders are compared bit for bit for sum and
mean: 512 fixture comparisons, in addition to analytical boundary cases.

```sh
python3 scripts/generate_sum_oracle.py --check
cargo test --locked --test sum_rounding_regressions --test aggregate_numeric_regressions --test math_precision_regressions
```

The superaccumulator principle is described by
[Neal (2015)](https://arxiv.org/abs/1505.05571); this code does not import the
paper's xsum implementation. Binary layout and bit conversions follow the
[Rust binary64 documentation](https://doc.rust-lang.org/std/primitive.f64.html).
These tests establish local numerical contracts, not an external GH oracle.

## NURBS surface area and plane projection

Area integration visits every nonzero native U/V knot cell. A pair of tensor
Gauss-Legendre rules (3 and 5 points per direction) guides subdivision. The
existing `steps` parameter remains serially compatible, with the UI label
“積分精度”; its convergence target is `1e-3 / steps^2`, for values 4 through 128.
Depth is limited to 12 and the number of surface samples to 262,144. Each sample
checks cancellation. Unresolved refinement, nonfinite results and insufficient
floating-point resolution are explicit errors.

The difference between the two quadratures is a numerical convergence
indicator, **not a certified geometric error bound**. Extreme rational weight
distributions can fail to converge within the budget. A misleading tiny finite
area is not an acceptable fallback. Analytic primitives retain their formulas.

Homogeneous surface evaluation uses a local control-point origin to retain
first and second derivatives under translation. Plane projection uses an
orthogonal frame and a compensated difference of products for its normal.
Boundary candidates are compared in the plane to avoid burying small distance
differences beneath a large shared normal distance.

The regressions use rectangles with uneven knots, a rational cylinder with
analytical area, translated rational derivatives and exactly representable
skew-plane inputs. See `tests/surface_numeric_regressions.rs` and
`OMEGA_VALIDATION.json` for executed test counts and the distinction between
the initial eight Rust reproductions and three later independent review cases.

## Curves and signed zero

Closest-point refinement includes the first and last sampled cells while
retaining exact endpoint candidates. It remains a bounded sampled search,
not a proof of the global minimum for an arbitrary curve. Closure tolerance
uses at most 19 geometric probes over the active interval, rather than endpoint
derivative speed. That conservative test is not an exact topological predicate.

The editor and history compare parameter bits in addition to structural
equality. In particular, changing `+0` to `-0` is a real edit: `atan2(y, -1)`
changes from `+pi` to `-pi`. Direct numeric entry, recomputation, dirty state,
undo/redo, cluster parameters and native JSON preserve that distinction.
