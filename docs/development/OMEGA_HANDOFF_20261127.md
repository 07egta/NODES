## 完成した実装

1. **グラフ診断**: 依存関係からの原因候補、重複しない影響先、無効・未評価・中断、
   実測した計算／キャッシュ再利用時間。エラー本文を解析して原因を決めず、
   実際に消費する入力だけをたどる。原因候補は証明された単独原因とは区別する。
2. **CLI**: `nodes-cli diagnose PROJECT.morph`。成功は
   `result.diagnostics`、評価失敗は終了コード1と `error.diagnostics`。
   評価前の読み込み・安全検証の失敗に架空の評価レポートを付けない。
3. **日本語 UI**: 「診断と処理時間」、ノードへの移動、名前／`#ID` 検索、
   各区分100行のページ、revision が古い場合の移動抑止。画面操作で再評価しない。
4. **数値処理**: 極端なスケールの行列消去、桁落ちする内積・外積、ほぼ平行な
   ベクトルの角度を、解析的な反例と Data Tree／実エンジンのテストで修正。
5. **値を見る**: 小さい非ゼロ／大きな数値の科学表記、ホバーの詳細値、
   「詳しい値をコピー」。数値・XYZの詳細文字列は有限値を再構成できる精度。
   キャンバスの既存入力エディタ全部を変更したものではない。
6. **診断中の協調キャンセル**: 新しいrevisionになったWorkerは古い診断を中止し、
   途中の評価／診断を公開しない。既存API・JSON契約を維持。標準ソートやグラフ検証の
   内部まで即時停止する保証はなく、無制限に短い停止応答時間は主張しない。
