# ラベル一覧

Issue と PR に付けるラベルの意味です。Issue テンプレートが自動で付けるものは「自動」と書いています。ラベルはリポジトリ側で作成しておく必要があります。

| ラベル | 意味 | 付ける目安 |
|---|---|---|
| `bug` | 動作の不具合・クラッシュ・誤った結果 | バグ報告（自動） |
| `enhancement` | 機能の追加・改善 | 機能提案・ノード要望（自動） |
| `node` | ノードの追加・変更 | ノード要望（自動）、ノード関連のPR |
| `ui` | 画面・操作・見た目 | 画面に関わる変更 |
| `gcode` | G-code 出力・プリンタ向けの処理 | G-code 関連 |
| `stl` | STL の入出力・メッシュ | STL 関連 |
| `docs` | 文書のみの変更 | README・docs・CONTRIBUTING の変更 |
| `good first issue` | 初めての人向けの小さな作業 | 作業範囲が小さく、手順を書けるもの |
| `help wanted` | 手を借りたい作業 | 誰でも取り組んでよいもの |
| `needs-triage` | 未確認（メンテナーが仕分け前） | 新規の Issue（テンプレートが自動付与） |
| `ai-generated` | AI ツールで作成・補助した PR | PR テンプレートの「AI生成」にチェックした PR |

## 運用メモ

- 仕分けが終わったら `needs-triage` を外し、種類のラベル（`bug` など）と領域のラベル（`ui` など）を付けます。
- `ai-generated` は作成者が付けます。付いていても、人の確認（CI・動作確認・ライセンス確認）が必要な点は変わりません。
- ラベル名は英語のまま使います。
