テンプレート: 角の丸い箱（厳密フィレット）、2 本の円柱のブーリアン、ロフトの花器（厳密立体・STEP 向け）、T-spline の有機的な花器。

「ロフトの花器」は数列から作った円の断面を SolidCraft でつなぎ、両端をふさいだ立体を生成します。

両方ともビューポートに表示して STL に書き出せます。CAD に渡す場合は **STEP 書き出し** へつなぎ、設定欄の **STEP を保存** を選びます。

## どう「改良して」取り込んだか

SolidCraft のカーネルはそのまま公開せず、`src/kernel_bridge.rs` で NODES 向けに包み直しました。

- **入力が少なく既定値が実用的**: フィレットは稜線を選ばなくても全稜線、シェルは上面を自動で開ける、ロフトは 3 断面以上で自動的に滑らか＋端面付き（失敗時は直線ロフトに切り替え）、回転体は開いた輪郭を自動で閉じる。
- **NODES の曲線をそのまま使える**: NODES の NURBS 曲線を各ノット区間の Bernstein 係数で厳密に Bézier 分解し、平面を当てはめて断面にします（円・円弧は有理 2 次のまま、3 次は 3 次のまま）。
- **許容差は 1 か所**: `kernel_bridge::tol`（同一点 1e-6 mm、角度 1e-9 rad、平面性 1e-4 mm、縫い合わせ 1e-4 mm、表示弦誤差は大きさの 1/1000 を 0.005〜0.25 mm に制限）。
- **日本語エラー（何が・なぜ・どう直す）**、キャンセル確認、面数・三角形数・STEP サイズの上限。
- カーネル内部の panic は `solidcraft_kernel::guard` でエラーに変わります。

カーネル本体のソースは変更していません（変更記録: [SOLIDCRAFT_CHANGES.md](SOLIDCRAFT_CHANGES.md)）。

## T-spline / SubD

- **円柱ケージ（格子ケージ）**: 周方向は周期的、高さ方向は端を通る一様 3 次 B-spline として面を厳密に定義します。表示・細分・B-rep 変換が同じ面を表します。細分はノット挿入（周方向は 3 次の中点則、高さ方向は SolidCraft `sc-geom` のノット挿入）で、形を変えずに点だけ増えます。B-rep 変換は面を 2 つに分けて SolidCraft の `tspline_sheet`（T-spline → NURBS 面）で面にし、縫い合わせ、上下をふさぎます。
- **箱ケージ・押し出し・折り目のあるケージ**: Catmull-Clark（折り目・境界は鋭いルール）。**B-rep 変換に対応**: Loop & Schaefer の近似 Catmull-Clark（ACC, 2008）で四角形 1 枚ごとに双三次 NURBS パッチを作り、縫い合わせて閉じた立体にします。正則な部分は Catmull-Clark の極限曲面と一致し、特異点（価数 3・5 など）のまわりは近似です（箱ケージ 1 回細分で、体積は細分メッシュと 2% 以内）。隣どうしのパッチは境界の制御点を同じビットで共有するので、隙間はできません。折り目は今のところ B-rep 変換では無視されます。四角形以外の面は 1 回細分してから変換します。
- **ケージ編集（直接編集モード）**: 「ケージ編集」ノードを選び「ビューポートで編集を始める」を押すと、ビューポートに制御網が出ます。点・辺・面モードでクリック選択（Shift で追加）、Ctrl＋ドラッグで移動、パネルから数値移動・拡大縮小・面の押し出し・折り目・細分・1 つ戻す。X/Y/Z の対称編集では鏡像の点も一緒に動きます（対称面上の点はその軸に動かない）。編集は JSON の一覧としてノードに保存され、開き直すと同じ結果が再生されます。

T-spline の特許については [TSPLINE_PATENTS.md](TSPLINE_PATENTS.md) を参照してください。方針として **SubD（Catmull-Clark）→ NURBS の経路を優先** しています。

## 次にやること

1. 星点（価数 3・5 など）まわりの G1: 今の ACC パッチは C0 なので、接線パッチ（Loop–Schaefer の ACC-2 や Gregory パッチ）で G1 にする。暫定として、星点まわりを先に細分する設定を入れた（G1 にはならないが、ずれは小さくなる）。円柱・箱ケージは T-spline パッチへ変換できるようにする。
1b. ブーリアンと厳密な交線が遅い（円柱 2 本で約 4 秒）。交線だけを求める処理をブーリアンから切り出し、面の組を事前に絞る。
2. ACC パッチの G1 改良（特異点まわりの接線パッチ）と、折り目を B-rep 変換に反映すること。
3. 開いた面どうしの厳密交線（今はメッシュ近似）と、NURBS 面どうしの交点を両方の面へ射影し直す処理（今は解析面のみ）。曲線と面の交点も同様。
4. トリム: 任意の平面では切れるようになった。別の面・曲線での分割とトリム（SolidCraft `split_faces` / `trim`）はまだノード化していない。
5. ネットワーク曲面の連続性指定（G1/G2）、稜線を画面で選んでブレンド・マッチの入力にすること（今は稜線番号）、連続性の解析結果を継ぎ目ごとに色で重ねて見せること。ブレンド曲面・曲面のマッチは入ったが、実機の GUI での使い心地は未確認。

7. ケージ編集: 3D ギズモ（軸ごとの移動・回転）、ループ選択、ケージの回転。

## 未検証・近似（正直なリスト）

- はじめの CI で開いていた直交円柱のメッシュは、SolidCraft の多面体ブーリアンを表示と STL 用に使うことで閉じます。入力メッシュが閉じており、作り直したメッシュの体積・範囲・トポロジーが許容内の場合に適用します。STEP と後続の形状演算には元の B-rep をそのまま渡します。
- 開いた面どうしの交線と、曲線と面の交点は表示メッシュ精度の近似です（弦誤差 `tol::chord`）。閉じた立体どうしの交線でも、NURBS 自由曲面の部分はカーネルの交線の点列をそのまま使います（射影し直しは解析面のみ）。
- 可変フィレットは直線の稜線だけ。ドラフト角は垂直な平面の壁だけ。曲面のシェルは `thicken`（平面・円柱は厳密、その他は 0.01 mm 以内の当てはめ）。
- ケージ編集の画面操作（クリック・Ctrl＋ドラッグ）は CI では確認できず、実機の GUI では未検証です。編集一覧の再生はテストしています。
- 有理で 3 次以上の曲線区間は短い直線で近似して断面にします。
- 2 レールスイープは SolidCraft の `SweepControl::rails` に 2 本目のレールを渡す方式で、Rhino の Sweep2 と同じ結果になるかは未検証です。
- ネットワーク曲面は曲線を点列として渡すため、元の曲線と完全一致はしません（SolidCraft の当てはめ許容差 1e-4 mm）。
- SolidCraft カーネル自身の単体テストは NODES の CI では実行していません（上流で実行）。
- 性能は [NURBS_PERFORMANCE.md](NURBS_PERFORMANCE.md) に実測を載せた分だけです。リリースビルド（LTO）と、コア数の多い PC は未計測です。
- 「曲率の表示」は表示メッシュからの近似で、メッシュが粗い所では帯がぎざぎざになります。厳密な曲率（曲面の第二基本形式）ではありません。
- ブレンド曲面・曲面のマッチは、2 つの縁の組み合わせによってはカーネルが失敗します（その場合は日本語のエラーになります）。
