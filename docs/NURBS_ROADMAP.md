# NURBS / B-rep カーネル ロードマップ（M1: 調査・方針・許容誤差）

目的は、Morphlet を Rhino 級の NURBS / B-rep モデラーへ段階的に育てること。このファイルは M1（調査と方針決定）の記録であり、M2 以降の受け入れ条件を定める。調査日は 2026-11-27 UTC。実装はすべて Rust、ライセンスは MIT / Apache-2.0 など許容的なもののみ。GPL / LGPL / AGPL のコードは使わず、読みもしない。

## 4. 決定

**当面は自前の幾何カーネルを育てる。`truck` と `curvo` は本体依存にせず、開発用の比較対象（オラクル）として使うに留める。** 本 PR では `Cargo.toml` と `Cargo.lock` を変更しない。

理由:

1. truck は最終リリースが 2024-09 で、メンテナンスが止まっている。ブーリアンは単純な円柱でも 3〜5 秒（debug）かかり、等半径の縮退配置で水密でなくなった。フィレット・シェルがなく、Rhino 級の目標の中心部分を補えない。
2. truck の必須依存に C ソース同梱の `lzma-sys` が入り、「Rust only」方針と配布の手間に反する。cgmath と nalgebra という別々の線形代数型が加わり、Morphlet 既存の `Point3` との変換が全域に必要になる。
3. curvo は小さく設計もよいが、曲面-曲面交差（SSI）とトリム曲面の水密な分割がない。それらが本体の難所で、依存しても自前実装が必要になる。nalgebra 型への全面変換が必要で、依存数も増える。
4. 既存の `curve_geometry.rs` / `surface_kernel.rs` は、有理 NURBS・厳密円・微分を既に持ち、中核の型を自前で持つほうが許容誤差ポリシーと一貫させやすい。
5. 部分的な採用余地は残す。STEP 出力（M11）は、自前 B-rep から `truck-stepio` 相当の書き出しを自作するか、`truck-stepio` を機能フラグ付きで採用するかを M11 で再評価する。M2〜M9 のテストでは `curvo` を `dev-dependency` として交点・loft の結果と突き合わせる案を、各 PR で採用可否を判断する。
6. 特許: T-spline は特許の状況が未確認であり、本計画では採用しない。SubD（Catmull-Clark）から NURBS へ変換する経路を優先する（M12）。

## 5. 許容誤差ポリシー

単一モジュール `src/tolerance.rs` に集約する。比較・判定にリテラルを散らさない。

| 名前 | 値 | 用途 |
|---|---|---|
| `ABS_TOL` | 1e-6 mm | 点の一致、距離比較、トリム端点の接続、頂点溶接 |
| `ANGLE_TOL` | 1e-9 rad | 平行・接線連続の判定 |
| `PARAM_TOL` | 1e-9 | ノット・パラメータの一致 |
| `ZERO_EPS` | 1e-12 | 除算の分母保護（`ABS_TOL` より小さい） |

- 長さは mm、角度は rad。
- 近似を伴う処理（offset、再構築、分割）は、呼び出し側から指定する許容を持ち、既定値は `ABS_TOL` 以上にならないよう各 API で明示する。
- 入力は敵対的とみなし、NaN と無限大は比較で常に「不一致」にする。パニックしない。
- 許容誤差を変える場合は、このファイルと `src/tolerance.rs` のテストを同時に更新する。

## 6. アーキテクチャ

UI から独立した幾何層 `geom` を作る。まずは単一クレート内のモジュール（`src/geom/`）で始め、API が安定した段階でワークスペース crate へ切り出す。egui・engine・graph への依存を持たない。

| 型 | 内容 | 初出 |
|---|---|---|
| `NurbsCurve` | 有理 NURBS 曲線（`curve_geometry.rs` を移設・拡張） | M2 |
| `NurbsSurface` | 有理 NURBS 曲面（`surface_kernel.rs` から分離） | M4 |
| `TrimmedSurface` | 基礎曲面 + パラメータ空間のトリムループ（外周 1 + 穴 n） | M7 |
| `Brep` | 頂点・辺・coedge・ループ・面・シェルを索引で持つ。各 coedge は辺と向きと、面上のパラメータ曲線を持つ | M6 |
| `SubdCage` | 制御ケージ（半辺構造）、クリース、細分割とリミット面 | M12 |

不変条件: 各辺は 2 つの coedge（多様体）、各ループは閉じる、coedge の 3D 曲線と 2D パラメータ曲線の差は `ABS_TOL` 以下、シェルの向きは一貫。検証器（validator）は M6 で追加し、以後の全演算の出力で必ず実行する。

## 7. マイルストーン M2〜M13 と受け入れテスト

各マイルストーンは 1 PR 1 主題。テストは既存の `tests/` の該当ファイルへ足す。

| M | 内容 | 受け入れテスト |
|---|---|---|
| M2 | 曲線の次数上げ、ノット削除、再構築（rebuild）、近似 | 次数上げ後に 1000 点で元曲線と `ABS_TOL` 以内。ノット削除は許容内で成功し、削れない場合はエラー。rebuild と近似の最大誤差を返し指定許容以下。円は厳密性を保つ |
| M3 | 曲線-曲線交差（平面・空間）、自己交差 | 円と円 2 点（解析解 1e-8 以内）、接する円 1 点、離れた円 0 点。ねじれの位置の曲線は距離が `ABS_TOL` 以下の場合のみ交差扱い |
| M4 | loft、revolve、sweep1 | 3 円 loft は水密な分割、境界は両端のみ。revolve した円柱・球の面積と体積が解析値と 1e-4 以内。sweep1 で断面の向きがねじれない |
| M5 | sweep2、network、patch | 2 本レールの sweep が両レールに `ABS_TOL` で接する。network は境界曲線を通る。patch は閉曲線で穴を埋め、元の曲線との距離が許容内 |
| M6 | 一般 B-rep のトポロジと検証器（箱専用の置き換え） | 箱・円柱・球を `Brep` で表し validator 合格。壊した入力（辺の欠損、向きの不一致）を検出し、パニックしない。既存の箱 API と体積が一致 |
| M7 | トリム曲面と、トリム対応の適応分割（水密） | 穴あき平面・トリムした球面の分割で、隣接面と共有する辺の境界辺数が 0（頂点溶接後）。面積が解析値と 1e-4 以内 |
| M8 | 曲面-曲面交差（SSI） | 平面-球、円柱-円柱（半径が異なる）、平面-トーラスで、交差曲線上の点が両曲面から `ABS_TOL` 以内。接する場合・分岐点で停止しパニックしない |
| M9 | ブーリアン（和・差・積） | 交差する円柱 2 本（半径 1.0 / 0.6）の和・差が validator 合格、体積が解析値と 1e-4 以内、2 秒以内（release）。等半径の縮退配置は成功するか、明確なエラーを返す |
| M10 | フィレット、面取り、シェル | 箱の全辺フィレットで接線連続（`ANGLE_TOL` 近傍）かつ validator 合格。シェルの厚み誤差が `ABS_TOL` 以内。失敗は理由付きのエラー |
| M11 | STEP 出力 | 箱・円柱・フィレット付き箱を STEP（automotive_design 系）で書き出し、パーサで読み戻して面数・体積が一致。出力は外部ツールでの読み込み確認を手順に記録 |
| M12 | SubD（Catmull-Clark）、クリース、リミット面 → NURBS 変換 | 立方体ケージの細分割が球に収束し、体積が単調に変化。クリース辺で鋭さが残る。リミット面から NURBS へ変換した誤差が指定許容以下。T-spline の特許状況は未確認のため採用せず、SubD → NURBS を優先する |
| M13 | SubD の直接編集モードとノード連携 | ケージの頂点・辺・面を直接編集でき、元に戻す・やり直しが効く。ノードグラフの入出力ポートで SubD と NURBS を受け渡し、保存した `.morph` を読み戻して同一結果 |
