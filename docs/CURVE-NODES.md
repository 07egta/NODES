# 直線・折れ線・等間隔分割

曲線カテゴリに4種類を追加しました。検索欄では「直線」「折れ線」「長さ」「等間隔」でも探せます。

| ノード | 入力→出力 | 使い方 |
|---|---|---|
| 2点から直線 | 始点・終点→曲線 | 2点を結ぶ有限線分です。同じ座標2つではエラーになります。 |
| 点列から折れ線 | 点のリスト・閉じる（0/1）→曲線 | 四角形なら一つの枝に4点を並べ、1にします。1枝につき1曲線。点を別の枝に分けると、一つの折れ線にはなりません。 |
| 曲線の長さ | 曲線→数値（mm） | 各線分の3D長さを足します。閉曲線では終点から始点へ戻る区間も含みます。 |
| 曲線を等間隔に分割 | 曲線・分割数（1〜1024）→点のリスト | 分割数は点の個数ではなく区間数です。開いた曲線は両端を含む N+1 点、閉じた曲線は始点を重ねない N 点。曲線上の弧長を等分するので、折れ角をまたぐ隣接点の直線距離は一定とは限りません。 |

「点列から折れ線」は空枝を保持します。空でない枝の点が不足する場合は枝パスを添えてエラーを表示します。閉じるには異なる頂点が3個以上必要で、手入力で末尾に書いた始点は一つだけ省きます。それ以外の重複頂点（閉曲線）や連続の同一点（どちらも）は拒否します。非平面輪郭や自己交差はこのノードの検査対象ではなく、面やソリッドを作れることは保証しません。開閉の入力は枝ごとに1個。開閉が1枝だけなら他の点枝に共有し、対応する設定がない枝は空になります。

「長さ」「等分」は現在の曲線の線分に対する計算です。円やらせんを分割したときは曲線ノードで指定した標本数に従い、NURBSや真円の厳密な弧長ではありません。等分の出力は点だけで、接線・曲線パラメータは出力しません。同じ枝内に複数曲線がある場合は、入力順に各曲線の点を同じ枝に並べます。

examples/curve-basics.morph には、5 mmの線分を4分割する例と、原点の周りに4点を置いて閉じた折れ線にする例があります。画面左側の点座標や分割数を変えて確認できます。このプロジェクトは追加ノードがある版で読み込んでください。既存のプロジェクトを読むために形式番号は変更していません。点・曲線は既存のOBJ/STL書き出しの対象外です。
