# NODES 開発版 — はじめての使い方

NODES は、ノードをつないで形や数値を作る独立型のパラメトリック CAD です。Rhino・Grasshopper のインストールやログインは不要で、基本のモデリング、保存、書き出しはオフラインで使えます。実行ファイル名は互換性のため **`NODES.exe`** を維持しています。

このガイドは **2026-11-27 の Ω 開発版**を対象にしています。メッシュ、数値、Data Tree に加え、数学的な NURBS 曲線・曲面と B-rep を扱います。登録は Cluster を含めて **370 種類**で、このうち SolidCraft を使う精密曲面は **33 種類**です。各ノードが対応する入力や操作は、設定欄やノード辞典で確認できます。

[最新の検証結果](../TEST_RESULTS.md) · [ノード対応表](../NODE_COVERAGE.md) · [開発状況](development/STATUS.md)

## 1. まず花器を編集して保存する

### 起動して作例を開く

配布物を展開し、`NODES.exe` を起動します。通常の初期作品は「ねじれの花器」です。復旧データなど別の作品が開いている場合は、上部の **作例・ヘルプ → 作品例**から選び直せます。

画面は、左のノードライブラリ、中央のキャンバス、右の 3D プレビューとノード設定で構成されます。ライブラリや右側が見えないときは **表示 → ノードライブラリ / 3D と設定**を確認してください。

### 花器の数値を変える

花器ノードの見出しをクリックし、右側の設定欄で次の値を試します。

| 設定 | 試す値 | 変化 |
| --- | ---: | --- |
| 半径 | 32 mm | 横幅 |
| 高さ | 120 mm | 全体の高さ |
| 波の数 | 7 | 周囲のひだの数 |
| 凹凸 | 0.18 | ひだの深さ |
| 肉厚 | 2.4 mm | 内壁と外壁の半径方向の間隔 |

設定欄ではスライダー操作と数値の直接入力を使えます。入力のラベルと値を確認し、入力欄からフォーカスを移して形の更新を待ってください。線がつながっている入力は接続元の値が優先され、設定欄に接続元が表示されます。

次に **ねじり**ノードを選び、ねじり角を `0°`、`90°`、`180°` と変えてみます。3D プレビューは左ドラッグで回転、ホイールで拡大・縮小できます。形が見切れたら **全体**、プレビューのダブルクリック、または `F` を使います。編集を戻すには `Ctrl+Z`、やり直すには `Ctrl+Y` を押します。

### 編集できる作品として保存する

上部の **保存**または **ファイル → 保存**を押し、フォルダーと名前を指定します。保存形式は **`.morph`** です。ノード、数値、配線、スクリプト、部品定義、グループなどを保存し、後から編集を続けられます。作例の原本を残す場合は **ファイル → 名前を付けて保存**を使ってください。

形状ファイルの STL / OBJ / 3MF はノードグラフの保存とは別です。印刷用データを書き出した後も、編集用の `.morph` を残してください。

## 2. 空のキャンバスから作る

1. **ファイル → 新規作品**を選びます。変更があれば、保存して進むか変更を破棄するかを選べます。
2. 左の検索、上部の **＋ ノード**、または `Tab` / `Ctrl+K` で「花器」や `vase` を探して追加します。
3. 花器を選択したまま「ねじり」や `twist` を追加します。型が合う接続先がある場合は自動で接続されます。
4. ねじりを選択したまま「出力」を追加します。配線を確認し、足りない線を手動で接続します。
5. 3D プレビューを **完成形**にして、花器とねじりの数値を調整します。

できあがるグラフは **花器 → ねじり → 出力**です。手動でつなぐには、接続元の右の丸から接続先の左の入力丸へドラッグするか、二つの丸を順にクリックします。

検索は日本語・英語と一部の言い回しに対応します。「円を作りたい」「点を並べたい」「花瓶をねじりたい」などを試せます。自由な文章から自動でグラフ全体を作る AI 機能ではなく、登録された語句や候補からノードを選ぶ仕組みです。

### ひとつの数値で複数の形を動かす

「数値」ノードを追加して値を `120` にし、その出力を花器の **高さ**入力へ接続します。同じ数値を別のノードにもつなげば、一度の変更で複数の形を調整できます。

手入力へ戻すには、接続済みの入力丸を右クリックするか、右側の設定欄の **切断**を押します。型が違う接続や循環する配線は拒否されます。

## 3. 主な操作

## 数値を線でつなぐ

複数の形をひとつの数値で調整するには、**数値**ノードを使います。

1. 「数値」を追加し、値を`120`にします。
2. 数値ノードの右側の丸をクリックし、花器ノードの左側にある**高さ**の丸をクリックします。ドラッグでつないでも構いません。
3. 数値ノードの値を変えると、花器の高さも変わります。

線で接続した入力は、接続元の値が優先されます。手入力へ戻すには、入力の丸を右クリックするか、右下の設定で**切断**を押してください。入力が直接設定に戻り、元の数値を編集できます。

**数列**ノードは複数の値をまとめて作ります。「輪郭からロフト」の作品例では、数列で円の半径と高さを変えています。まず作品例の数値を変えて、右下の**データを見る**で枝と要素数を確認すると理解しやすくなります。

## ノード一覧（追加分）

0.1.0の28種類に、次の14種類を追加しました。**この追加分はまだコンパイル・実機での動作確認をしていません。** 不具合を見つけたら教えてください。左の検索欄では日本語・英語どちらでも探せます。

| ノード | 英語の検索語 | できること |
|---|---|---|
| 円柱 | `cylinder` | 半径・高さ・周の分割から、底と蓋のある円柱を作る |
| 円錐 / 角錐 | `cone` `pyramid` | 円錐を作る。周の分割を3にすると三角錐、4で四角錐 |
| トーラス | `torus` | 主半径・副半径・分割数からドーナツ形を作る。副半径は主半径より小さく |
| 平面 | `plane` `grid` | 幅・奥行・分割数の格子状の平面。閉じていない面なので書き出し検査では開いた辺が出ます |
| ミラー | `mirror` | 原点を通る面（軸 0:X 1:Y 2:Z に垂直）で反転。「元も残す」を1にすると元の形と反転形を1つにまとめる |
| 非一様スケール | `scale` `stretch` | X・Y・Zを別々の倍率（0.01〜100）で拡大縮小。原点基準 |
| 引き算 | `subtract` | A − B |
| べき乗 | `power` | 底の指数乗。0の負の指数や、負の数の小数乗はエラー |
| 絶対値 | `abs` | 符号を取り除く |
| 最小 / 最大 | `min` `max` | AとBの小さい方 / 大きい方（2つの別ノード） |
| 剰余 | `modulo` `mod` | 余り（0以上 \|B\| 未満）。Bが0のときはエラー |
| 三角関数 | `sine` `sin` | 振幅 × sin(2π × 周波数 × 入力 + 位相)。位相は度 |
| 範囲 | `range` | 開始から終了までを等間隔に分けた数値リスト。個数は512まで |

数値ノードの結果が大きすぎる、または計算できない値になる場合は、NaNや無限大を作らず、日本語のエラーとして表示します。

## リスト・式・3Dプリント向けのノード（未検証）

Grasshopperで花器やパターンを作るときによく使われる流れ（半径をグラフで決める → ノイズやねじりで変化をつける → 厚みをつけて印刷できる壁にする、点をばらまいて引力点からの距離で大きさを変える）を、このアプリでも組めるように20種類を追加しました。**コンパイル・実行による確認はまだです。** Grasshopperの定義をそのまま読み込めるわけではありません（対応表: [Grasshopperとの対応](GH_COVERAGE.md)）。

### リストを扱う

リスト系のノードは、ブランチ（枝）ごとに「リスト全体」を受け取ります。番号は 0 から数えます。

| ノード | 英語の検索語 | できること |
|---|---|---|
| リスト項目 | `list item` | 番号の位置の要素を取り出す。「折り返す」1 なら -1 が最後、範囲外は先頭へ戻って数える。番号にリストをつなぐと複数取り出す |
| リスト長 | `length` | 要素の数。空なら 0 |
| 反転 | `reverse` | 並びを逆にする |
| 並べ替え | `sort` | 数値を小さい順に。大きい順は続けて反転 |
| 間引きパターン | `cull` | 1 と 0 のパターンをくり返し当てて、0 の位置を除く。パターンは「剰余」などで作ってつなぐ |
| シフト | `shift` | 要素を前へずらす。「折り返す」0 ならはみ出しを捨てる |
| 連結 | `concat` `join` | リスト A の後ろに B をつなぐ |
| 部分リスト | `sub list` `slice` | 開始番号から個数分を取り出す |

### 数値・式・乱数

| ノード | 英語の検索語 | できること |
|---|---|---|
| 範囲を調べる | `bounds` | 数値リストの [最小, 最大] |
| 再マップ | `remap` | 元の範囲（リストの最小〜最大、または指定）から新しい範囲へ比例で置き換え。新しい最小と最大を逆にすると大小が反転 |
| 式 | `expression` | x・y・z・w を使った数式。式は右下の設定欄で書き、Enter か「適用」で反映。全角で入力しても使えます。256文字・入れ子24段まで |
| 乱数 | `random` | シードで決まる乱数のリスト。同じシードなら毎回同じ |
| ランダムな点 | `populate` | 箱の中に決まったシードで点をばらまく |
| ノイズ | `noise` `perlin` | 位置からなめらかに変化するノイズの値 |
| 距離 | `distance` | 2点の距離 |
| 点の成分 | `component` | 点の X・Y・Z のどれかを数値に |

式で使えるもの: `+ - * / % ^`（`^` はべき乗で右から計算）、定数 `pi`、`e`。角度はラジアンです。0での割り算、定義域外の値、非有限の計算結果などは日本語のエラーになります。

| 関数 | 用途 |
|---|---|
| `sin(x), cos(x), tan(x), asin(x), acos(x), atan(x), atan2(y,x)` | 周期・逆三角関数・象限を考慮した角度 |
| `sinh(x), cosh(x), tanh(x)` | 双曲線関数 |
| `sqrt(x), cbrt(x), abs(x), hypot(x,y)` | 根・絶対値・平面上の距離 |
| `ln(x), log2(x), log10(x), exp(x)` | 対数・指数 |
| `log1p(x), expm1(x)` | 0付近でも精度を維持しやすい `ln(1+x)`、`exp(x)-1` |
| `floor(x), ceil(x), round(x), min(x,y), max(x,y)` | 丸め・比較 |
| `clamp(x,lo,hi)` | lo〜hi に制限（lo ≤ hi） |
| `lerp(a,b,t)` | 線形補間。t=0でa、t=1でb。範囲外は外挿。 |
| `smoothstep(x,lo,hi)` | 0〜1の滑らかな遷移（lo < hi）。引数順はNODES独自の規約。 |

例: `lerp(20,45,smoothstep(x,0,1))` を花器の半径へ接続すると、x=0〜1で急な変化のない半径制御ができます。[編集可能な作例](../examples/math/smooth-vase-radius.morph)。

### 3Dプリント向け

| ノード | 英語の検索語 | できること |
|---|---|---|
| グラフで形を決める | `graph` `profile` | 下から上へ並べた半径のリストをなめらかにつないで、底のある器を作る（上は開いたまま。「上を閉じる」1 で閉じた立体） |
| ノイズ変形 | `noise deform` | ノイズで頂点を押し出す。方向 0 は中心軸から外向き、1 は面の向き、2 は上下 |
| 厚みをつける | `shell` `thicken` | 面を内側へずらして縁をつなぎ、印刷できる壁にする |
| 張り出しチェック | `overhang` | 下向きの面のうち、垂直から指定角度より寝ている面の [面積の割合 %, 面の数, 最大の角度] |

**厚みをつけるの注意：** 近似の計算です。頂点の向きの平均方向へずらし、角では厚みが保たれるよう最大2倍まで伸ばします。厚みが形の細い部分（くびれ・とがった所）より大きいと、内側の面が交差しても検出できません。書き出し前の検査も自己交差は調べないので、スライサーで確認してください。

**花瓶モード（らせん1本で印刷）について：** 張り出しが大きい器は花瓶モードで失敗しやすくなります。張り出しチェックの割合が 0 に近いことを目安にしてください（判定は面の角度だけで、印刷の成功を保証しません）。

## ノードの選び方（未検証）

コンパイルもテスト実行もしていません。CIが最初の確認になります。

### ノード棚

画面上部の**ノード棚**に、ノードがカテゴリごとのタブで並びます。

- タブ: 先頭の**★ お気に入り**と、各カテゴリ（数値・データ・曲線・立体・変形・配列・出力など）。カテゴリはノードの分類から自動で作られます。
- ボタン: アイコンと名前が出ます。ポインタを乗せると、説明と「入力 → 出力」の型が出ます。
- クリック: 選択中のノードがあれば、その右に追加し、型が合う最初の入力へ線をつなぎます。なければキャンバスの中央に追加します。
- ドラッグ: キャンバスの好きな場所で離すと、そこに配置します（線はつながりません）。
- 右クリック: ★ をお気に入りに追加・外します。

### おすすめ次のノード

ノードを1つ選ぶと、右側に**おすすめ次のノード**が最大6個出ます。選んだノードの出力を受けられるもの（最初の入力の型が合うもの）だけを、★お気に入り → 最近使ったもの → その他の順に並べます。クリックすると、その場に追加して線をつなぎます。

### 検索を開く（Tab・Space）

- `Tab` / `Ctrl+K`: 検索ウィンドウを開きます。ポインタがキャンバス上にあれば、その位置に追加されます。
- `Space` を押して離す: キャンバス上でも検索が開きます。`Space` を押したままドラッグすると、従来どおりキャンバスが動きます。
- 検索の候補にもアイコンが出ます。右クリックで ★ を付け外しできます。

### お気に入りと最近使ったノード

★お気に入りと最近使ったノードは、画面の明暗の設定と同じ設定ファイル（`settings.txt`）に保存され、次に起動したときも残ります。

## 曲線・メッシュ・形の追加分（未検証）

曲線を作る、管や断面で立体にする、メッシュを直す、形を曲げ・すぼめる、格子状の網目を作る、ための18種類を追加しました。**コンパイル・実行による確認はまだです。** 対応表は [Grasshopperとの対応](GH_COVERAGE.md) を参照してください。

### 曲線を作る・分ける

| ノード | 英語の検索語 | できること |
|---|---|---|
| 円弧 | `arc` | 半径・開始角度・終了角度（度）・分割数で円弧の点列 |
| 点をつなぐ線 | `polyline` | 点のリストを順につなぐ。「閉じる」1 で閉じた輪郭 |
| なめらかな曲線 | `spline` `smooth curve` | 点を通る Catmull-Rom 曲線。サンプル数で細かさを決める |
| 曲線のオフセット | `offset` | 閉じた平面の曲線を外（+）・内（−）へずらす。角の上限を超える角は面取り。自分と交わる結果はエラー |
| 曲線上の点 | `point on curve` | 長さの割合 0〜1 の位置の点 |
| 曲線を等分割 | `divide` | 長さで等しく分けた点のリスト |

### 管・断面で立体にする

| ノード | 英語の検索語 | できること |
|---|---|---|
| パイプ | `pipe` `tube` | 曲線に沿う円い管。「端を閉じる」1 で開いた曲線の両端にふた。曲がりが急だと内側がつぶれる |
| スイープ | `sweep` | XY 平面の閉じた断面を、パスに沿って動かした面（両端は開いたまま） |
| 回転体の輪郭 | `revolve points` `lathe` | 点のリストを Z 軸のまわりに回す。輪郭の両端が軸上なら閉じた立体 |

### メッシュを直す・調べる

| ノード | 英語の検索語 | できること |
|---|---|---|
| なめらかにする | `smooth` `taubin` | 強さ・回数で角を丸める。方式 1 は縮みを抑える。境界の頂点は動かさない |
| 細分化 | `subdivide` | 三角形の辺の中点で 4 分割。1〜3 段階。上限で止まる |
| 頂点をくっつける | `weld` | 許容差より近い頂点をまとめる。STL の重なった頂点の修復に |
| 面の向きをそろえる | `unify normals` | 隣り合う面の向きをそろえ、閉じた形は外向きにする |
| メッシュ情報 | `mesh info` `volume` | [頂点数, 三角形数, 体積, 表面積] の 4 つの数値 |

### 曲げる・すぼめる・並べる・網目

| ノード | 英語の検索語 | できること |
|---|---|---|
| テーパー | `taper` | 下の倍率から上の倍率へ、X・Y を Z に沿って変える |
| 曲げ | `bend` | 指定した軸のまわりに曲げる。曲げ角が大きすぎると折り重なるのでエラー |
| 格子配列 | `grid array` | X・Y・Z の個数と間隔で格子状に複製（個数の積は 512 まで） |
| ジャイロイド | `gyroid` `tpms` | 箱の中の網目（閉じた立体）。単位の大きさ・壁の太さ・分解能（最大 64）。壁の太さは 0〜1 の目安で、mm の厚さではありません |

**注意:** ジャイロイドは、分解能を上げるほど計算に時間がかかり、形も大きくなります。上限を超えるとエラーになるので、分解能か単位の大きさを変えてください。

| 保存・別名保存 | `Ctrl+S` / `Ctrl+Shift+S` |
| 作品を開く | `Ctrl+O`、上部の**開く**、または`.morph`ファイルをウィンドウへドロップ |
| ノードのヘルプ | ノードを選んで`F1`、ノード見出しの**?**、または上部の**ノード辞典** |
| 使い方・表示サイズ変更 | 上部の**?**。下部に表示サイズがあります |

## 4. 値・リスト・Data Tree を確認する

ひとつのノードには、1 個の値、複数の値のリスト、枝に分かれた Data Tree が流れます。枝は `{0}`、`{0;1}` のような path で識別します。

この開発版のグラフは、1 ノードにつき一つの出力を持ちます。主曲率やメッシュ診断などで複数の数値が出る場合も、別々の出力ポートではなく、同じ出力内のリストとして扱うものがあります。

ノードを選び、設定欄の **値を見る**を開くと、枝・要素番号・値を確認できます。**別ウィンドウで開く**やキャンバス上部の **値を見る**で大きく表示できます。数値表示は小数 4 桁、表は最大 500 行です。この表示桁数は、保存している数値を 4 桁へ丸める設定ではありません。

曲線は NURBS / 解析曲線 / 折れ線の区別、メッシュは頂点・三角形数、曲面は数学曲面の種類、B-rep は面・稜線などを表示します。更新中の表示は前回の結果の場合があるので、更新待ちの案内も確認してください。

| 操作 | 用途 |
| --- | --- |
| 数列・範囲 | 等間隔の数値を作って、半径・高さ・位置などへ接続 |
| リスト項目・リスト長 | 0 から数えた位置の値を取り出す、要素数を調べる |
| 反転・並べ替え・シフト | 枝内の並びを変更 |
| Flatten | 枝をひとつへまとめる |
| Graft | 要素を別の枝へ分ける |
| Simplify | 共通する path の階層を整理 |
| Path Mapper | 制限された path 変換構文で枝を移す。例は設定欄に表示 |

対応ノードの **データツリー設定**では、入力ごとの Flatten / Graft / Simplify と、Longest / Shortest / Cross のマッチングを選べます。すべてのノードが同じ入力アクセスではありません。既定の枝対応には既存作品との互換性を維持する設定もあるため、入力の Item / List / Tree 表示と値 viewer を確認します。Grasshopper のすべての Data Tree 挙動を検証済みという意味ではありません。

### 式と数値の扱い

**式**ノードは `x`・`y`・`z`・`w` を使います。たとえば `sin(x) * 10 + y`、`(x - 5) ^ 2`、`max(x, y)` を入力し、**適用**または入力欄からのフォーカス移動で反映します。式の三角関数はラジアンです。ほかのノードは度を使うものもあるので、入力ラベルを確認してください。

0 での割り算、許可されない値、計算結果の overflow などはノードのエラーになります。設定欄には処理時間と、計算 / キャッシュ / 前回の評価などの状態も表示されます。

## 5. 精密曲線・曲面を使う

### NURBS 曲線

**Bezier 曲線 / NURBS 曲線 / 有理 NURBS / 補間曲線**などがあります。有理 NURBS は制御点、正の重み、完全ノット列、次数を扱います。表示用の点列と数学的な曲線は別に保持されます。

対応する曲線には、評価点、接線、長さ、曲率、分割、制御点・重み・ノットの取得などを利用できます。ただし、最近接点の探索や一部の操作は近似計算で、一般の曲線交差・offset・fillet を完全に備えてはいません。ノード名や辞典の「近似」「preview」などの説明を確認してください。

### NURBS 曲面を見てメッシュへ変換する

1. **NURBS パネル**を追加します。
2. 幅・奥行・中央制御点高さを設定します。選択ノードのプレビューで曲面を確認できます。
3. **曲面をメッシュ化**を追加し、曲面入力へ接続します。
4. そのメッシュを **出力**へつなぎます。U分割・V分割で近似メッシュの細かさを調整できます。

これで **NURBS パネル → 曲面をメッシュ化 → 出力**になります。パネルは開いた面なので、この手順だけで厚みのある閉じた印刷用立体になるわけではありません。

ほかに、4 点からの曲面、解析的な円筒・球など、対応する断面からの線織曲面、押し出し、等値曲線、法線、曲率があります。作成方法と入力条件は限定されており、任意の CAD 曲面を読み込んで編集する機能ではありません。現在の **曲面の最近接点**は平面曲面に限定されます。

### B-rep とメッシュを区別する

**B-rep 箱**はメッシュとは別の閉じた立体です。対応する箱の体積・表面積や限定的な箱同士の演算を利用できます。STL などへ出すときは **B-rep をメッシュ化 → 出力**へ接続します。

**精密曲面**カテゴリの **厳密直方体**・**厳密円柱**や **ロフトして立体** などは SolidCraft の B-rep を作ります。
**立体の和・差・積**、**フィレット**、対応形状の **シェル** で加工できます。丸める場所と寸法によって加工できる範囲が変わります。

### STEP ファイルを読み書きする

1. **STEP 読み込み** を配置し、右側の **ファイルを選ぶ** で `.step` または `.stp` を開きます。
2. NODES で作った B-rep を保存する場合は **STEP 書き出し** へつなぎ、設定欄の **STEP を保存** を押して保存先を選びます。
3. 試すには **ロフトの花器（厳密立体・STEP 向け）** のテンプレートを開き、出力の手前のロフトから線を分けてつなぎます。

## 7. STL / OBJ / 3MF を書き出す

### 書き出す形を選ぶ

上部の **書き出し**、または **ファイル → STL / OBJ 書き出し**を押します。ダイアログの **書き出す形**には次の二つがあります。

| モード | 対象 |
| --- | --- |
| **完成形（出力ノード）** | 作品内の出力ノード。出力ノードが一つもない場合だけ、現在の選択を対象にする |
| **選択ノード** | キャンバスで選んだノード。途中の形を書き出すときに明示して選ぶ |

対象ノードの計算エラーや更新待ちがある場合は、案内に従って修正・再計算を待ちます。別の正常な形だけを意図せず部分保存しないよう、対象と寸法を確認してください。

書き出しに使うのは **Mesh 型の結果**と **SolidCraft の B-rep の表示用メッシュ**です。数学曲面は **曲面をメッシュ化**、旧来の **B-rep 箱**は **B-rep をメッシュ化**を経由します。`nodes-cli export-stl` を使う場合は SolidCraft の B-rep も **B-rep → メッシュ**で変換してから **出力**へつなぎます。

### 形式・倍率・置き方を確認する

| 形式 | 用途と範囲 |
| --- | --- |
| **STL バイナリ（おすすめ・小さい）** | 3D プリント用の三角形メッシュ |
| **STL テキスト（ASCII）** | テキスト形式の STL |
| **OBJ（3D ソフト用）** | メッシュの頂点・面。材質やテクスチャを含む完全なシーン交換ではない |
| **3MF（試験的）** | 対応するメッシュを 3MF package として保存。スライサーの印刷設定を含むプロジェクト保存とは異なる |

現在の 3MF 書き出しは、各オブジェクトに閉じた多様体・そろった面方向・正の符号付き体積を要求します。空洞の内側の殻を独立したオブジェクトにすることや、自己交差・複数オブジェクトの重なりを自動で解決することには対応していません。

単位は mm を前提にします。STL 自体には単位指定がないため、読み込み先でも mm として扱っているか確認してください。cm のモデルには倍率 ×10、inch には ×25.4 を使用できます。倍率は書き出し時の設定です。

**ベッドに置く（一番低い所を Z=0） / 作った位置のまま**を選び、必要なら XY 中心を原点へ合わせます。**離れた部品ごとに別ファイルにする**では複数のファイルになります。保存先の案内と実際に保存されたファイル一覧を確認してください。

### 検査・修復・保存

1. 寸法、部品数、三角形数、開いた境界、面方向、非多様体、重複・退化面などの検査を確認します。
2. 必要なら **自動修復**を試します。修復内容を読んで、形が意図したものか確認してください。書き出し用のメッシュに適用され、元のノードグラフは変更しません。
3. **書き出す…**で保存先を指定します。検査に問題があると **それでも書き出す…**と表示される場合がありますが、形式や形状の妥当性検査で保存を拒否する場合もあります。
4. **スライサーで開く**から外部スライサーを起動できます。見つからない場合は実行ファイルを指定します。
5. 編集後の **すぐ書き出し** / `Ctrl+Shift+E` は、この作品で直前に書き出したファイルを更新します。作品を開いた直後やアプリの再起動後は、保存先を選びます。

自動修復は一般の自己交差修正や任意の穴埋めを保証しません。検査で問題が見つからなくても、最小肉厚、支持、材料・造形条件、実機での印刷成功を保証するものではありません。3MF を含め、スライサーで最終的な寸法・向き・層の状態を確認してください。

## 8. STL / OBJ を読み込む

1. **ファイル読み込み**ノードを追加し、右側で **ファイルを選ぶ**を押します。STL / OBJ をウィンドウへドロップして追加することもできます。
2. 倍率、**XYを原点へ**、**床に置く Z最小=0**を調整します。
3. 出力を変形ノードや **出力**へつなぎます。

バイナリ / ASCII STL と、OBJ の頂点 `v`・面 `f` を読み込みます。OBJ の法線、テクスチャ、材質などは保持しません。対応する単純で平面上の凹多角形は三角形へ分割します。自己交差、非平面、退化した OBJ の面などは拒否します。STL では退化三角形を除外するため、面数が減ることがあります。

上限はファイル 64 MiB、頂点 250,000、三角形 500,000 です。同じ位置に近い頂点を結合しますが、それだけで閉じた正常な立体になる保証はありません。読み込み後も mesh 診断を確認します。

読み込み元ファイルのパスを作品に保存するため、ファイルを移動・削除すると再選択が必要です。更新日時やサイズの変化は次のグラフ評価で再読み込みの対象になります。

## 9. スクリプトと部品

### スクリプトノード

**スクリプト**を追加して選ぶと、設定欄に Rhai のコードを書く欄が出ます。入力 **a・b・c・d**は数値、**g**は接続した形状で、未接続でも利用できます。複数の値はリストになります。**適用**またはコード欄からのフォーカス移動で反映します。

最後の式が出力です。数値、点、対応するメッシュ、そのリストなどを返せます。たとえば次のコードは a 個の数値を作ります。

```rhai
let out = [];
for i in 0..to_int(a) {
    out.push(b * sin(radians(c * i)));
}
out
```

設定欄の **例1: らせん階段 / 例2: 波の数列**でもコードを読み込めます。数学関数、`point(x,y,z)`、`mesh_box`、`mesh_cylinder`、`mesh_move`、`mesh_rotate`、`mesh_scale`、`mesh_merge` などを使用できます。`mesh_rotate` の角度は度、通常の `sin` / `cos` はラジアンです。

現在の Script は入力の枝を flatten し、結果を単一の `{0}` branch へ返します。名前付き複数出力や、Surface / Solid の直接入力は未対応です。精密曲面・B-rep を使う場合は先に明示的にメッシュ化してください。

実行には操作数 20 万回、進行チェックによる 2 秒の制限、スクリプト 8 KiB、文字列 4,096 文字、リスト 8,192 個、関数呼び出し 16 段などの制限があります。ファイル・ネットワーク・`import`・`eval` は利用できません。これらは制限付き実行の仕組みで、任意のコードに対する OS プロセス全体の強制的なメモリ隔離を提供するものではありません。

### まとめノード（Cluster）

1. まとめたいノードを複数選び、右側の設定欄で **まとめる**を押します。
2. 外へ渡す出力は一つにします。外部との接続や必要な入力から、最大 8 個の公開入力を作ります。
3. 作った部品は `.morph` 内に保存され、左の **部品（まとめノード）**から再配置できます。
4. **部品として書き出す（.morphpart）**で別ファイルにし、**部品を読み込む…**で別の作品へ取り込めます。

入れ子は 4 段、1 定義 256 ノード、1 作品 64 定義までです。現在は複数出力の公開、部品の中身をキャンバスで直接編集する画面、まとめ解除は未対応です。部品名は設定欄で変更できます。

> この章には、追加時点で未検証とされた機能も含まれます。「値を見る」の数値表示と「診断と処理時間」は、現在の操作に合わせて説明しています。

**作例・ヘルプ → 作品例**には 10 種類の内蔵作例があります。ねじれの花器、光のリング、星のトーテム、螺旋のスケッチ、波打つブロック、輪郭からロフト、サイン波の塔、べき乗の山脈、ノイズの花器、引力点のパターンを選べます。

リポジトリの [examples](../examples) には **37 個の `.morph` グラフ**があり、曲線・NURBS・曲面・生成デザインなども含みます。内蔵の一覧にない作例は **ファイル → 開く**から読み込みます。数値を変え、別名で保存して、再度開いて編集できます。

曲線だけの作例はそのまま STL へ出せません。開いた曲面の作例には閉じた印刷用形状にするための追加処理が必要です。各作例の編集・保存・再読み込み・再評価を対象とする自動テストがあり、その実行結果は [TEST_RESULTS.md](../TEST_RESULTS.md) に記録しています。すべての作例の実機印刷を確認したという意味ではありません。

## 11. GHX と外部連携の範囲

### 限定的な GHX inspect / convert

ノードを選ぶと、右下の設定欄の**値を見る**に、枝（`{0}`など）・番号・値の表が出ます。点は`(x, y, z)`、曲線は点の数、メッシュは頂点数と三角形数です。表示は500行までで、残りは「…ほか N 件」と数だけ表示します。**別ウィンドウで開く**またはキャンバス上部の**値を見る**で、大きなウィンドウでも見られます（選んだノードに合わせて切り替わります）。「パネル」ノードを置かなくても中身を確認できます。

数値と座標の各成分は、通常は小数4桁で表示します。絶対値が `0.0001` 未満の非ゼロ値や、`1,000,000` 以上の値は指数表記になります。たとえば `5.0000e-19` は、10のマイナス19乗を5倍した値です。小さな値をゼロと取り違えずに確認できます。ゼロの符号は `0.0000` と `-0.0000` で区別します。一覧の文字列を読みやすく丸めても、計算結果の精度は保持します。

数値や座標にポインターを重ねると、**詳しい値**が表示されます。右クリックして**詳しい値をコピー**を選ぶと、計算結果の精度を保つ数値表記をコピーできます。座標は `(x, y, z)` の形式です。詳しい表示やコピーには指数表記を使い、非常に小さな値でもゼロが長く続く文字列にならないようにしています。

開発者向けには、GHX の内容を JSON report に保存する inspect と、ごく小さい scalar subset を `.morph` へ変換するコマンドがあります。リポジトリルートからの例です。

```sh
cargo run --locked --bin NODES -- --inspect-ghx examples/interop/scalar-point.ghx report.json
cargo run --locked --bin NODES -- --convert-ghx examples/interop/scalar-point.ghx converted.morph
```

変換対象は、対応する **Number Slider と Construct Point**の scalar 入力などに限定されます。Panel、Toggle、Group、未知の component や設定は report に調査情報を残しますが、未対応のものを含む graph を不完全な `.morph` として変換しません。取り込んだスクリプトを実行する機能ではありません。report は調査用データで、GUI の未対応ノードを編集・再保存できる仕組みとは異なります。

詳しい条件は [GRAPH_INTEROPERABILITY.md](GRAPH_INTEROPERABILITY.md) を参照してください。native `.morph` の未知のノードや field は現在読み込みを拒否し、未知ノードを placeholder として保持する editor は未実装です。

### 自動化・未対応形式

コンソール版 **nodes-cli** は catalog、validate、evaluate、build、apply、export-stl を JSON 入出力で扱えます。制限付き Graph API はスクリプトや外部ファイルを実行する機能を許可していません。操作例は [CLI.md](CLI.md) を参照してください。GHX 用の上記オプションとは別の入口です。

GH binary、STEP、IGES、3DM、glTF / GLB、Grasshopper の GHA plugin の読み込みは未対応です。3MF は試験的な書き出しで、3MF の読み込みやスライサー設定の完全な往復を含みません。外部プラグイン ABI や汎用 MCP server、自然言語からのグラフ自動生成も完成していません。

## 12. G-code 花瓶モードについて

### G-code ノード（「Gコード」カテゴリ）

**STL が主な書き出しで、G-code は補助機能です。実機では一度も印刷を確認していません。コンパイル・テストの実行結果は CI で確認してください。初回は必ず印刷を見守り、開始・終了の G-code とベッド寸法を機種の説明書と照らしてください。**

メニューの「G-code（花瓶モード）」とは別に、ノードをつないで G-code を作れます。流れは次のとおりです。

1. **プリンタ設定**（機種を選ぶ。Bambu A1 mini は原点が角の版と、中心 90,90 の版があります。FlashForge Creator 5、TRONXY Moore 1（粘土）、Marlin 汎用）
2. 設定ノード（**速度設定**、**温度・ファン**、**リトラクト**、**Zホップ**、**押出量計算**、**粘土用設定**）を好きな順でつなぐ。**輪切りより前**につなぐと、経路づくりに値が使われます（速度・温度・リトラクトなどは書き出し時の最終値が使われます）。
3. **輪切り**（閉じたメッシュ → 層ごとの輪郭）
4. **等高線パス**（壁の本数・外壁が先か内壁が先か・底の塗りつぶし）または **らせん連続Z**（花瓶モード。1 周で 1 層分、周の長さに比例して Z を上げます）
5. 必要なら **経路の並び替え**（最近傍）、**経路の分割**、**ノンプラナー変形**、**波・テクスチャ付加**、**開始Gコード** / **終了Gコード**、**Gコード結合**
6. **パスプレビュー**（速度・押出の進み・層・種類で色分けして 3D 表示）、**時間・材料見積り**（数値で出る）、**安全チェック**（日本語の警告が「値を見る」に出る）
7. **Gコード書き出し**（ノードを選ぶと右に「.gcode を書き出す…」が出ます）

押出量は **E = 長さ × 線幅 × 層の高さ ÷ (π(フィラメント径/2)²) × 流量** です。E は絶対（M82）と相対（M83）を選べ、開始 G-code のあとに **M82 または M83 と G92 E0 を必ず出力**します。

**安全面：** 書き出しは「安全チェック」でエラー（ベッドの外、数値でない座標、過押出など）があると拒否します。ファイルは保存画面で選び、既存のファイルは確認なしに上書きしません。保存は一時ファイル経由で、失敗しても元のファイルは残ります。開始・終了 G-code に書く文章は、使える文字と長さを検査します（中身が機種に合うかは検査できません）。

**制限と未対応：**

- Bambu Lab の `.gcode.3mf`（公式の方法）は未対応です（TODO）。生の G-code は未検証です。
- 壁を 2 本以上にするオフセットは単純な方法で、尖った角や細い部分では崩れることがあります。
- 経路数・点数・出力サイズに上限があります。超えると日本語のエラーになります。
- 粘土用の E の単位（押出筒の直径の設定）は機種ごとに異なる可能性があり、実機での校正が必要です。ベッド寸法・原点は仮の値です。
- 書き出しの文字列づくりは画面の操作スレッドで行います。経路が非常に多いと少し待たされます。
- 「横切り移動」の判定は目安で、すべての衝突を見つけるものではありません。

作例は「シンプル花瓶→らせんGコード」（A1 mini）と「波模様の粘土の器」（Moore 1）です。設計は FullControl（GPL）を参照せず、独自に実装しています。

### 診断と処理時間

画面下のステータス行にある**診断**、または上部メニューの**表示 → 診断と処理時間**から開きます。直近の計算結果を使う画面で、開くだけで再計算は行いません。

**入力とエラー**では、まず**最初に確認する原因候補**を見ます。`#番号 名前 ↗` のボタンを押すと、そのノードをキャンバスで選択して画面内に表示し、入力や設定を調べられます。**上流にエラーがあるノード**を開くと、各ノードのエラーメッセージと上流の候補への移動ボタンも表示されます。1行の上流候補ボタンは最大8件で、残りがある場合は件数を案内します。

原因候補は、失敗したノード同士の接続関係から絞っています。上流の候補を直しても、下流に別の未接続入力や設定の問題が残る場合があります。候補を確認した後は、更新されたエラーメッセージに沿って修正してください。**無効なノード**と**未計算のノード**は別の一覧で確認でき、グラフ全体の接続・構造の問題も区別して表示します。

上部の欄には名前の一部分を入力でき、`#123` のように書くとノードIDを指定できます。**クリア**で絞り込みを解除します。各一覧には「該当 / 全」の件数があり、100件を超えると**前の100件**・**次の100件**で続きを見られます。原因候補、下流のエラー、無効、未計算、処理時間の各一覧は、それぞれページを切り替えられます。検索条件を変えると先頭ページに戻ります。

計算中は前回の結果が表示される場合があります。その間は案内が付き、ノードへの移動は新しい結果に更新されてから使えます。

**処理時間**では、今回の評価で実際に時間のかかったノードを上から確認できます。ここでもノードのボタンからキャンバスへ移動できます。

| 表示 | 時間の意味 |
|---|---|
| 計算 | 入力の準備、ノードの計算、出力の検査にかかった今回の時間 |
| 再利用 | 前回の結果を取得・確認するなど、再利用の処理にかかった今回の時間。元の結果を作ったときの計算時間は含めない |
| 中断まで | そのノードの処理を始めてから中断までに測定できた時間 |

単位はミリ秒（`ms`）で、部品ノードは内部の処理を含みます。割合（`%`）は、測定できた有効ノードの時間合計に対する値です。CPU使用率を表す数字ではありません。**キャッシュから再利用したノードも表示**をチェックすると、再利用したノードの行も確認できます。すべて再利用された場合は、このチェックを付けて取得時間を見てください。

検索やチェックで非表示にしたノードも、割合の分母には含まれます。表示中の行だけで100%に換算し直す表示ではありません。診断レポート自体を作る時間も、このノード時間合計には含みません。

## 13. うまくいかないとき

| 状態 | 確認すること |
|---|---|
| ノードが赤くなる | カード下の赤い帯・画面下のステータス行・右下の**値を見る**で理由を確認。複数のエラーがあるときは**診断**の原因候補から調べる |
| 小さな計算結果がゼロか分からない | **値を見る**の指数表記を確認し、数値にポインターを重ねて**詳しい値**を見る |
| 処理時間の一覧にノードが出ない | 計算中かどうかと名前・IDの絞り込みを確認。結果を再利用した場合は**キャッシュから再利用したノードも表示**をチェック |
| 形が消えた | ノードが**無効**（灰色・「（無効）」表示）になっていないか確認。`Ctrl+E`で戻せます |
| 線がつながらない | 入力と出力の型を確認。数値と形状など、合わない接続は拒否します |
| 後ろから前へつなげない | 同じ計算を循環させる接続は作れません。失敗した接続で元の配線は消えません |
| 形が表示されない | **完成形**なら出力ノードへの接続、**選択ノード**なら選択中のノードを確認 |
| 文字・数値が小さい | `F1`で表示サイズを変更。ノードの数値は右下の設定でも編集可能 |
| ねじりが角張る | 元の花器や押し出しの**縦の分割**を増やす |
| 花器の肉厚エラー | 高さや最小半径に対して肉厚が大きすぎないか確認 |
| 式が赤い | 設定欄の式の下に出る理由を確認。使える文字は x・y・z・w・pi・e と数字・記号だけです |
| 厚みをつけるがエラー | 厚みを小さくする。面の向きがそろっていないメッシュや、1つの辺を3枚以上の面が共有するメッシュには使えません |
| 大きな作品で簡略表示になる | プレビューの表示上限に到達しています。書き出しは元の形状を使います |
| STL/OBJを書き出せない | 出力へメッシュを接続。数値・点・曲線だけでは書き出せません |
| スクリプトが赤い | 赤いノードの「データを見る」にある日本語の理由を確認（行番号つき）。無限ループ・大きすぎるリスト・使えない関数が主な原因です |
| `.morph`を開けない | エラーメッセージを確認。壊れたファイルや未知の形式を開こうとしても、現在の作品は置き換わりません |

変更がある間は約 20 秒間隔で復旧用の保存を試みます。これは自分で選んだ `.morph` への保存に代わるものではありません。作業の区切りで **保存**してください。Undo/Redo は最大 64 操作分です。
