# Morphlet 0.1 — はじめての使い方

Morphlet（仮称）は、ノードをつないで立体や曲線を作る独立したデスクトップアプリです。Rhinoのインストールやログインは不要で、モデリング・保存・書き出しをオフラインで行えます。この版はメッシュと折れ線を扱います。

## まず3〜5分で、ひとつ作る

### 1. 起動して作品例を開く

配布ファイルを展開し、`Morphlet.exe`を起動します。初回は「ねじれの花器」が開きます。別の作品を試すときは、画面上部の**作品例**または左下の**作品例からはじめる**を押し、好きな作品の**開く →**を選びます。

左がノードのライブラリ、中央がノードキャンバス、右上が3Dプレビュー、右下が選択したノードの設定です。

### 2. 花器の大きさを変える

中央の**花器**ノードの見出しをクリックします。右下の設定で、たとえば次の値を試してください。

| 設定 | 試す値 | 変わるところ |
|---|---:|---|
| 半径 | 32 mm | 花器の横幅 |
| 高さ | 120 mm | 花器の縦の長さ |
| 波の数 | 7 | 周囲のひだの数 |
| 凹凸 | 0.18 | ひだの深さ |
| 肉厚 | 2.4 mm | 内壁と外壁の半径方向の間隔 |

スライダーを動かすか、数値欄をクリックして直接入力できます。中央のノード内でも数値を調整できます。ノードを小さく表示しているときは、右下の設定を使うと読みやすくなります。

### 3. ねじってみる

**ねじり**ノードを選び、**ねじり角**を`0°`、`90°`、`180°`と変えてみます。花器の下側から上側へ回転量が増え、形が変化します。

右上の3Dプレビューはドラッグで回転できます。形が見切れたら**全体**を押すか、プレビューをダブルクリックしてください。編集しすぎたときは`Ctrl+Z`で戻せます。

### 4. 編集できる作品として保存する

画面上部の作品名を変更し、**保存**を押します。アプリ内のファイル選択画面でフォルダーと名前を選び、`.morph`形式で保存します。このファイルにはノード・数値・配線などが入っており、後から続きを編集できます。

### 5. 形状を書き出す

**書き出し ↗**を押し、形状の確認画面から**STL · 3D プリント**または**OBJ · 3D ソフト**を選びます。書き出されるのは**出力**ノードにつないだメッシュです。出力ノードがない場合は選択ノードを対象にします。複数の出力のどれかにエラーがあれば、部分的な形状を黙って保存せず、修正を案内します。

STL自体には標準の単位指定がないため、スライサーへ読み込むときは**mm**として解釈してください。

## 空のキャンバスから花器を作る

1. 左下の**空のキャンバスを開く**を押します。未保存の変更がある場合は、保存して進むか、変更を破棄するかを選べます。
2. 左の検索欄で「花器」または`vase`を探し、クリックして追加します。
3. 花器を選択した状態で「ねじり」または`twist`を追加します。型が合う必須入力には、選択中のノードから自動で線がつながります。
4. ねじりを選択した状態で「出力」を追加します。
5. 右上を**完成形**にし、花器とねじりの数値を調整します。

グラフは**花器 → ねじり → 出力**になります。自動接続を使わずに、各ノードの右側の丸から、次のノードの左側にある**形状**の丸へ線をつないでも作れます。

**出力**ノードがまだないときは、**選択ノード**モードで途中の形を確認できます。出力ノードを置いて形状入力を接続していない場合、完成形には何も表示されません。

## 数値を線でつなぐ

複数の形をひとつの数値で調整するには、**数値**ノードを使います。

1. 「数値」を追加し、値を`120`にします。
2. 数値ノードの右側の丸をクリックし、花器ノードの左側にある**高さ**の丸をクリックします。ドラッグでつないでも構いません。
3. 数値ノードの値を変えると、花器の高さも変わります。

線で接続した入力は、接続元の値が優先されます。手入力へ戻すには、入力の丸を右クリックするか、右下の設定で**切断**を押してください。入力が直接設定に戻り、元の数値を編集できます。

**数列**ノードは複数の値をまとめて作ります。「輪郭からロフト」の作品例では、数列で円の半径と高さを変えています。まず作品例の数値を変えて、右下の**データを見る**で枝と要素数を確認すると理解しやすくなります。

## ノード一覧（追加分）

0.1.0の28種類に、次の14種類を追加しました。**この追加分はまだコンパイル・実機での動作確認をしていません。** 不具合を見つけたら教えてください。左の検索欄では日本語・英語どちらでも探せます。

| ノード | 英語の検索語 | できること |
|---|---|---|
| 円柱 | `cylinder` | 半径・高さ・周の分割から、底と蓋のある円柱を作る |
| 円錐 / 角錐 | `cone` `pyramid` | 円錐を作る。周の分割を3にすると三角錐、4で四角錐 |
| トーラス | `torus` | 主半径・副半径・分割数からドーナツ形を作る。副半径は主半径より小さく |
| 平面 | `plane` `grid` | 幅・奥行・分割数の格子状の平面。閉じていない面なので書き出し検査では開いた辺が出ます |
| ミラー | `mirror` | 原点を通る面（軸 0:X 1:Y 2:Z に垂直）で反転。「元も残す」を1にすると元の形と反転形を1つにまとめる |
| 非一様スケール | `scale` `stretch` | X・Y・Zを別々の倍率（0.01〜100）で拡大縮小。原点基準 |
| 引き算 | `subtract` | A − B |
| べき乗 | `power` | 底の指数乗。0の負の指数や、負の数の小数乗はエラー |
| 絶対値 | `abs` | 符号を取り除く |
| 最小 / 最大 | `min` `max` | AとBの小さい方 / 大きい方（2つの別ノード） |
| 剰余 | `modulo` `mod` | 余り（0以上 \|B\| 未満）。Bが0のときはエラー |
| 三角関数 | `sine` `sin` | 振幅 × sin(2π × 周波数 × 入力 + 位相)。位相は度 |
| 範囲 | `range` | 開始から終了までを等間隔に分けた数値リスト。個数は512まで |

数値ノードの結果が大きすぎる、または計算できない値になる場合は、NaNや無限大を作らず、日本語のエラーとして表示します。

## リスト・式・3Dプリント向けのノード（未検証）

Grasshopperで花器やパターンを作るときによく使われる流れ（半径をグラフで決める → ノイズやねじりで変化をつける → 厚みをつけて印刷できる壁にする、点をばらまいて引力点からの距離で大きさを変える）を、このアプリでも組めるように20種類を追加しました。**コンパイル・実行による確認はまだです。** Grasshopperの定義をそのまま読み込めるわけではありません（対応表: [Grasshopperとの対応](GH_COVERAGE.md)）。

### リストを扱う

リスト系のノードは、ブランチ（枝）ごとに「リスト全体」を受け取ります。番号は 0 から数えます。

| ノード | 英語の検索語 | できること |
|---|---|---|
| リスト項目 | `list item` | 番号の位置の要素を取り出す。「折り返す」1 なら -1 が最後、範囲外は先頭へ戻って数える。番号にリストをつなぐと複数取り出す |
| リスト長 | `length` | 要素の数。空なら 0 |
| 反転 | `reverse` | 並びを逆にする |
| 並べ替え | `sort` | 数値を小さい順に。大きい順は続けて反転 |
| 間引きパターン | `cull` | 1 と 0 のパターンをくり返し当てて、0 の位置を除く。パターンは「剰余」などで作ってつなぐ |
| シフト | `shift` | 要素を前へずらす。「折り返す」0 ならはみ出しを捨てる |
| 連結 | `concat` `join` | リスト A の後ろに B をつなぐ |
| 部分リスト | `sub list` `slice` | 開始番号から個数分を取り出す |

### 数値・式・乱数

| ノード | 英語の検索語 | できること |
|---|---|---|
| 範囲を調べる | `bounds` | 数値リストの [最小, 最大] |
| 再マップ | `remap` | 元の範囲（リストの最小〜最大、または指定）から新しい範囲へ比例で置き換え。新しい最小と最大を逆にすると大小が反転 |
| 式 | `expression` | x・y・z・w を使った数式。式は右下の設定欄で書き、Enter か「適用」で反映。全角で入力しても使えます。256文字・入れ子24段まで |
| 乱数 | `random` | シードで決まる乱数のリスト。同じシードなら毎回同じ |
| ランダムな点 | `populate` | 箱の中に決まったシードで点をばらまく |
| ノイズ | `noise` `perlin` | 位置からなめらかに変化するノイズの値 |
| 距離 | `distance` | 2点の距離 |
| 点の成分 | `component` | 点の X・Y・Z のどれかを数値に |

式で使えるもの: `+ - * / % ^`（`^` はべき乗で右から計算）、`sin cos tan sqrt abs min max floor ceil round ln exp`、`pi`、`e`。角度はラジアンです。0での割り算、負の数の平方根、大きすぎる結果などは日本語のエラーになります。

### 3Dプリント向け

| ノード | 英語の検索語 | できること |
|---|---|---|
| グラフで形を決める | `graph` `profile` | 下から上へ並べた半径のリストをなめらかにつないで、底のある器を作る（上は開いたまま。「上を閉じる」1 で閉じた立体） |
| ノイズ変形 | `noise deform` | ノイズで頂点を押し出す。方向 0 は中心軸から外向き、1 は面の向き、2 は上下 |
| 厚みをつける | `shell` `thicken` | 面を内側へずらして縁をつなぎ、印刷できる壁にする |
| 張り出しチェック | `overhang` | 下向きの面のうち、垂直から指定角度より寝ている面の [面積の割合 %, 面の数, 最大の角度] |

**厚みをつけるの注意：** 近似の計算です。頂点の向きの平均方向へずらし、角では厚みが保たれるよう最大2倍まで伸ばします。厚みが形の細い部分（くびれ・とがった所）より大きいと、内側の面が交差しても検出できません。書き出し前の検査も自己交差は調べないので、スライサーで確認してください。

**花瓶モード（らせん1本で印刷）について：** 張り出しが大きい器は花瓶モードで失敗しやすくなります。張り出しチェックの割合が 0 に近いことを目安にしてください（判定は面の角度だけで、印刷の成功を保証しません）。

#### 3Dプリント向けの表示（未検証）

- **寸法・体積・重さ**：プレビュー左上に、形の寸法（X×Y×Z mm）、体積（cm³）、PLA（密度 1.24 g/cm³）で中実と仮定した重さの目安、三角形の数、閉じたメッシュかどうかを表示します。穴あけ・インフィル・外殻を考えていないため、実際の印刷重量は軽くなります。開いたメッシュでは体積は参考値です。
- **造形台**：**なし**・**Bambu A1**（256×256×256 mm）・**Bambu A1 mini**（180×180×180 mm）・**FlashForge Adventurer 5M**（220×220×220 mm）・**カスタム**から選ぶと、造形範囲の枠と10 mm間隔の格子を表示します。形は枠の中央に、底面を造形台に合わせて置いたものとして描きます。
- **はみ出し**：形の寸法が造形範囲を超えると、枠と説明文が赤になり、超えた軸（X・Y・Z）を示します。向きを変えて入れる自動配置はしません。形を回転させるか、ノードで寸法を変えてください。
- **張り出し**：**張り出し**をオンにすると、下向きに急な面をオレンジで表示します。角度（既定45°）は右の欄で変えられます。判定は**張り出しチェック**ノードと同じ基準で、造形台に載っている面は対象外です。

## スクリプトノード（自由に作る）

> 未検証の機能です（ビルド・実行していません）。

ライブラリの「スクリプト」を置いて選ぶと、右下の設定に書く欄が出ます。入力 **a・b・c・d** は数値、**g** はつないだ形状です（なくても動きます）。複数の値がつながっているときは、a〜d・gはリストになります。**最後に書いた値**が出力になり、数値・数値のリスト・点・メッシュを返せます。書いたら**適用**を押します（欄から外れても適用されます）。

| 使えるもの | 内容 |
|---|---|
| 数学 | `sin cos tan asin acos atan atan2 sqrt exp ln abs floor ceil round pow min max clamp lerp radians degrees pi()`（整数でも小数でも可） |
| 数列 | `linspace(始め, 終わり, 個数)`（「範囲」ノードと同じ。Rhai標準の `range(a, b)` は整数用でそのまま使えます） |
| 点 | `point(x, y, z)`、`p.x` `p.y` `p.z` |
| メッシュ | `mesh_box(幅, 奥行, 高さ)`、`mesh_cylinder(半径, 高さ, 分割数)`、`mesh_move(m, x, y, z)`、`mesh_rotate(m, 度)`（Z軸）、`mesh_scale(m, 倍率)`、`mesh_merge(m1, m2)` または `mesh_merge(リスト)` |
| 文法 | `let`、`if`、`for i in 0..n`、`while`、リスト `[]`、`fn` など（Rhai） |

安全のための制限：実行は20万回・2秒まで、文字列は4,096文字、リストは8,192個まで、スクリプトは8 KiBまで、関数の入れ子は16段までです。ファイル・ネット・`import`・`eval` は使えません。超えるとノードが赤くなり、理由が日本語で出ます。

**例1：らせん階段**（a=段数 b=半径 c=1段の回転角 d=1段の高さ。初期値のまま動きます）

```
// a=段数  b=半径  c=1段ごとの回転角(度)  d=1段の高さ
let n = to_int(a);
let parts = [];
for i in 0..n {
    let ang = radians(c * i);
    let step = mesh_box(b * 0.5, b * 0.25, d * 0.4);
    step = mesh_rotate(step, c * i);
    step = mesh_move(step, b * cos(ang), b * sin(ang), d * i);
    parts.push(step);
}
mesh_merge(parts)
```

**例2：波の数列**（a=個数 b=振幅 c=1つごとの角度。「移動」のZなどへつなぐと波になります）

```
// a=個数  b=振幅  c=1つごとの角度(度)  → 数値のリストを返す
let n = to_int(a);
let out = [];
for i in 0..n {
    out.push(b * sin(radians(c * i)));
}
out
```

設定欄の「例1」「例2」ボタンで、この2つを入れられます。

## まとめノード（部品）

> 未検証の機能です（ビルド・実行していません）。

1. まとめたいノードをまとめて選び、右下の「ノードの設定」で**まとめる**を押します。
2. 選んだノードが1つの「まとめノード」になります。出力は「選択内で他に使われていないノード」です（外へつながる出力は1つだけにしてください）。
3. 外からつながっていた入力、形状の接続が必要な入力、そして数値の入力（最大8個まで）が、まとめノードの入力になります。
4. 部品は作品（`.morph`）の中に保存されます。ライブラリ下部の「部品」から、同じ部品をもう一度置けます。
5. **書き出し**で `.morphpart` ファイルにでき、**部品を読み込む…**で別の作品へ入れられます。

制限：入れ子は4段まで、1つの部品は256ノードまで、1作品に64個まで。いまは「まとめを解除」と、部品の中身を開いて編集する画面はありません（定義の名前だけ変更できます）。

## 迷わないための機能（値を見る・ヘルプ・無効・グループ・メモ）

> 未検証の機能です（この追加分はビルド・実行していません。CIでのコンパイルが最初の確認になります）。

### 線の見た目でデータの形がわかる

Grasshopper系のツールでつまずく原因のほとんどは「いま流れているのが1個なのか、リストなのか、ツリーなのか」が見えないことです。Morphletでは線と出力の丸の横の小さな札で区別します。

| 線 | 札の例 | 意味 |
|---|---|---|
| 細い実線 | `1` | 値が1個 |
| 二重の太い線 | `12` | 1本のリストに12個 |
| 点線 | `{3}×12` | ツリー：3本の枝に合計12個 |
| 灰色の細かい点線 | `0` | 空（無効にしたノードなど） |

札は最後に計算が終わった結果から作ります。形を変えている途中は、1つ前の結果のままのことがあります。

### 値を見る

ノードを選ぶと、右下の設定欄の**値を見る**に、枝（`{0}`など）・番号・値の表が出ます。数値は小数4桁、点は`(x, y, z)`、曲線は点の数、メッシュは頂点数と三角形数です。表示は500行までで、残りは「…ほか N 件」と数だけ表示します。**別ウィンドウで開く**またはキャンバス上部の**値を見る**で、大きなウィンドウでも見られます（選んだノードに合わせて切り替わります）。「パネル」ノードを置かなくても中身を確認できます。

### ヘルプ（オフライン）

ノードを選んで`F1`を押すか、選択中のノード見出しの**?**を押すと、そのノードの説明・入力（種類・既定値・範囲・つなぐ必要があるか）・出力の種類・使い方のヒントが出ます。上部の**ノード辞典**では全ノードを分類ごとに一覧でき、検索や**＋ キャンバスに追加**もできます。インターネットは使いません。

### ノードを無効にする

`Ctrl+E`（または見出しの右クリック→**無効にする**）で、選択中のノードを一時的に止められます。無効のノードは灰色になり、何も出力しません（空）。下流のノードは「入力待ち」やエラーになることがあります。もう一度`Ctrl+E`で元に戻ります。無効の状態は`.morph`に保存されます。

### グループとメモ

- ノードを選んで`Ctrl+G`で、色つきの枠（グループ）で囲みます。枠の見出しをクリックすると中のノードを選択、ドラッグでまとめて移動、右クリックで名前・色の変更と**解除**ができます。ノードを削除すると枠も自動で縮みます。
- キャンバスの空白を右クリック→**ここにメモを追加**で、付箋のようなメモを置けます。ダブルクリックで編集、ドラッグで移動、右クリックで削除です。
- グループとメモは計算に影響しません。`.morph`に保存されます（1作品にそれぞれ256個まで、メモは1つ4096バイトまで）。

### エラーの場所

計算できないノードは、カードの下に赤い帯で日本語の理由を表示します（マウスを重ねると全文）。画面下のステータス行にも、選択中のノード（なければ最初のエラー）の名前と理由が出ます。

## ファイルを読み込む（未検証）

STLやOBJの形を、ノードの材料として使えます。コンパイルもテスト実行もしていません。CIが最初の確認になります。

1. 追加メニューで **ファイル読み込み** を選ぶか、STL・OBJのファイルをウィンドウへドラッグします。ドラッグした場合は、最後に確認したマウスカーソルの位置へ追加されます（位置が取れないときは画面の中央）。
2. 右の設定で **ファイルを選ぶ** を押し、STLまたはOBJを選びます。
3. 倍率（既定値 1）、**XYを原点へ**（既定 1）、**床に置く Z最小=0**（既定 1）を調整します。0 にすると、その処理は行いません。
4. 出力へつなぐと、3Dプレビューと書き出しに使えます。

対応しているのは、バイナリSTL、ASCII STL（`solid`で始まるテキスト）、頂点（`v`）と面（`f`）だけのOBJです。法線やテクスチャの行は無視します。多角形の面は扇形に三角形へ分けます。同じ位置の頂点は1つにまとめるので、閉じたファイルは閉じたメッシュとして扱われます。

上限は、ファイル 64 MiB、頂点 250,000、三角形 500,000 です。壊れたファイル・途中で切れたファイル・NaNや無限大の座標は、赤いエラーとして表示されて読み込みません。ファイルを書き換えると、次の計算で読み直します。

面積がゼロの面は捨てるため、読み込んだ面数が元のファイルより少ないことがあります。
## G-code で花瓶を印刷する（花瓶モード・未検証）

STLの書き出しが主な方法です。G-codeは補助機能で、上部バーの **その他の書き出し → G-code（花瓶モード・未検証）** から使います。

1. 「出力」ノードに、閉じた1つの形状をつなぎます（複数の形状は書き出せません）。
2. 機種（Bambu Lab A1 mini / A1、FlashForge 汎用、Marlin 汎用）を選ぶと、ベッドの大きさが入ります。
3. 層の高さ・線幅・温度などを決め、**見積もりを計算** で層数・印刷時間・フィラメント量を確認します。
4. **G-code として保存…** で `.gcode` を書き出します。

- 形状はベッドの中央に置かれ、外周 10 mm を除いた範囲に収まらないと書き出せません。
- 底は数層を塗りつぶし、その上を1枚の壁の螺旋で印刷します。上面は開いたままです。
- 開始・終了のG-codeは一般的な例で、機種ごとの動作は確認していません。**Bambu Lab の機種は Bambu Studio で .gcode.3mf を書き出すのが公式の方法です。**
- 初回は必ず印刷を見守り、ノズルの高さ・温度・ベッドへの密着を確認してください。

## うまくいかないとき

| 状態 | 確認すること |
|---|---|
| ノードが赤くなる | カード下の赤い帯・画面下のステータス行・右下の**値を見る**で原因を確認 |
| 形が消えた | ノードが**無効**（灰色・「（無効）」表示）になっていないか確認。`Ctrl+E`で戻せます |
| 線がつながらない | 入力と出力の型を確認。数値と形状など、合わない接続は拒否します |
| 後ろから前へつなげない | 同じ計算を循環させる接続は作れません。失敗した接続で元の配線は消えません |
| 形が表示されない | **完成形**なら出力ノードへの接続、**選択ノード**なら選択中のノードを確認 |
| 文字・数値が小さい | `F1`で表示サイズを変更。ノードの数値は右下の設定でも編集可能 |
| ねじりが角張る | 元の花器や押し出しの**縦の分割**を増やす |
| 花器の肉厚エラー | 高さや最小半径に対して肉厚が大きすぎないか確認 |
| 式が赤い | 設定欄の式の下に出る理由を確認。使える文字は x・y・z・w・pi・e と数字・記号だけです |
| 厚みをつけるがエラー | 厚みを小さくする。面の向きがそろっていないメッシュや、1つの辺を3枚以上の面が共有するメッシュには使えません |
| 大きな作品で簡略表示になる | プレビューの表示上限に到達しています。書き出しは元の形状を使います |
| STL/OBJを書き出せない | 出力へメッシュを接続。数値・点・曲線だけでは書き出せません |
| スクリプトが赤い | 赤いノードの「データを見る」にある日本語の理由を確認（行番号つき）。無限ループ・大きすぎるリスト・使えない関数が主な原因です |
| `.morph`を開けない | エラーメッセージを確認。壊れたファイルや未知の形式を開こうとしても、現在の作品は置き換わりません |

変更がある間は約20秒間隔で復旧用の自動保存を試み、次回起動時に復旧データがあれば続きから開けます。作業を確実に残すときは、**保存**で自分の`.morph`ファイルも作ってください。Undo/Redoは最大64操作分です。

## この版の範囲

Morphlet 0.1は63種類のノード（うち35種類は未検証の追加分）とスクリプトノードを備えた、独立したノード式メッシュモデラです。円・ロフト・回転面も、内部では分割した点列や三角形として作ります。

**本物のNURBS・B-rep、STEP、Rhinoの3DM、GrasshopperのGH/GHX、GHAプラグイン、AIによるノード生成、ブーリアン演算は未実装です。** 「メッシュをまとめる」は複数のメッシュをひとまとめにする処理で、重なりを取り除く和演算ではありません。

プレビューの面は、既定では小さなソフトウェアの奥行きバッファで描きます（未検証。20万三角形まで）。ワイヤー表示中や**正確な奥行き**をオフにしたときは従来の並べ方式で、交差部分の前後が正しくない場合があります。線・点は面より前に描かれます。書き出し前の検査は辺のつながりを中心としたもので、自己交差・最小肉厚・3Dプリント成功を判定する機能ではありません。花器の肉厚は半径方向の値です。

Windows用ビルドは用意していますが、Windows実機での操作確認は未実施です。確認した環境と結果は[検証記録](VERIFICATION.md)、保存形式や出力の詳しい仕様は[保存・出力の実装範囲](IO_NOTES.md)を参照してください。
