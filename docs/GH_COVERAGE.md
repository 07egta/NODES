# Grasshopperとの対応（よく使う機能）

Morphletは独立実装で、Grasshopperの定義（GH/GHX）を読み込んだり、結果の一致を保証したりはしません。この表は「Grasshopperでよく使われる考え方を、Morphletではどのノードで組めるか」の目安です。説明文はすべてこのプロジェクトで書いたものです。

**状態の意味：** 確認済み = 配布版0.1.0で動作確認したもの。未検証 = コードとテストを書いたが、まだコンパイル・実行していないもの（CIが最初の確認）。未実装 = まだ無いもの。

## 3Dプリントの器・ランプ

器やランプのGrasshopper作品では、輪郭をグラフや曲線で決め、高さに沿ってねじり・拡大縮小し、ノイズで表面を揺らし、最後に厚みをつける流れがよく使われます（面のままでは印刷できないため）。花瓶モードでは張り出しが寝すぎると失敗しやすくなります。

| よく使う考え方 | Morphletのノード | 状態 | 違い・制限 |
|---|---|---|---|
| グラフで輪郭を決める | グラフで形を決める | 未検証 | 半径のリストをCatmull-Rom曲線でなめらかにつなぐ方式のみ。ベジェなどグラフの種類の切り替えはない |
| 輪郭を回転して器にする | 回転面、グラフで形を決める | 確認済み / 未検証 | |
| 高さに沿ってねじる | ねじり | 確認済み | 回転量は高さに比例のみ |
| 高さに沿って拡大縮小 | 範囲 → 式 → グラフで形を決める | 未検証 | 専用の「高さに沿った拡大」ノードはない |
| パーリン系ノイズで表面を揺らす | ノイズ、ノイズ変形 | 未検証 | 独自の決定的なグラディエントノイズ。他ソフトのノイズ値とは一致しない |
| 厚みをつける | 厚みをつける | 未検証 | 頂点法線方向のオフセットと縁の縫い合わせによる近似。自己交差は検出しない |
| 張り出し（オーバーハング）の確認 | 張り出しチェック | 未検証 | 面の角度だけで判定。ブリッジ・サポート・層ごとの検討はしない |

## 作品例

- `09.morph` **ノイズの花器（厚みつき）**：範囲 → 式（半径） → グラフで形を決める → ノイズ変形 → ねじり → 厚みをつける → 出力。張り出しチェックの結果を「データを見る」で確認できます。
- `10.morph` **引力点のパターン**：ランダムな点と引力点の距離を再マップして円柱の高さにし、点の X・Y で移動します。

どちらも未検証です。
