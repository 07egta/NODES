## 曲線・メッシュ修復・形の変形（追加分、未検証）

この節の対応は独立実装の目安です。Grasshopper の標準部品と同じ結果になるとは限りません。

| よく使う考え方 | NODESのノード | 状態 | 違い・制限 |
|---|---|---|---|
| 円弧 | 円弧 | 未検証 | 分割点の折れ線。解析的な円弧ではない |
| 点列から折れ線 | 点をつなぐ線 | 未検証 | 「閉じる」で閉じた輪郭 |
| 点を通る曲線 | なめらかな曲線 | 未検証 | Catmull-Rom のみ。ベジェなど他の種類はない |
| 曲線のオフセット | 曲線のオフセット | 未検証 | XY 平面の閉じた曲線のみ。角は面取り上限つき。自己交差は拒否 |
| 曲線上の点・等分割 | 曲線上の点、曲線を等分割 | 未検証 | 長さで分ける（パラメータ分割ではない） |
| パイプ | パイプ | 未検証 | 平行移動フレームの近似。急な曲がりでは内側が潰れる |
| スイープ | スイープ | 未検証 | 1 本のパス、閉じた断面のみ。端は開いたまま |
| 回転体（Revolve） | 回転体の輪郭 | 未検証 | 点列から Z 軸まわりに回す。X・Y の距離を半径にする |
| メッシュのスムージング | なめらかにする | 未検証 | ラプラシアン・テイコフ。境界は固定 |
| 細分割（Subdivide） | 細分化 | 未検証 | 中点分割 1〜3 段階のみ |
| 頂点の結合（Weld） | 頂点をくっつける | 未検証 | 許容差の格子で結合。格子の境界をまたぐ近い頂点は結合しない |
| 法線の統一（Unify） | 面の向きをそろえる | 未検証 | 連結部品ごとに体積の符号で外向きにする |
| メッシュ情報（Mesh Properties） | メッシュ情報 | 未検証 | 頂点数・三角形数・体積・表面積の 4 数値 |
| テーパー・曲げ | テーパー、曲げ | 未検証 | 指定軸に沿った線形の倍率と円弧状の曲げのみ |
| 格子配列（Grid） | 格子配列 | 未検証 | 直交格子のみ。個数の積は 512 まで |
| ジャイロイド（TPMS） | ジャイロイド | 未検証 | 箱の中の閉じた網目。マーチング四面体で等値面を作る（立方体テーブルは使わない）。壁の太さは 0〜1 の無次元の目安 |

## 標準部品の追加分（未検証・CIで確認）

`src/gh_gaps.rs` の17ノードと、配線用の「リルート点」を追加しました。Grasshopper の結果と同じとは限りません。

| 分野 | NODESのノード | 備考 |
|---|---|---|
| Maths | 平方根、二乗、三乗、立方根、自然対数、常用対数 | 範囲外（負の平方根・0以下の対数）はエラー |
| Maths | 論理 NAND / NOR / XNOR、範囲に含まれるか | 論理値は 0 / 1。範囲は両端を含む |
| Vector | 極座標の点、円柱座標の点 | 原点中心。平面入力は未対応 |
| Curve | 曲線の面積、曲線の面積重心、曲線を線分に分解 | 表示用の点列（折れ線）から計算。閉じた平面曲線のみ（面積・重心） |
| Transform | 向きを合わせて回転、水平面へ投影 | 回転は原点中心。向きは XYZ の数値で指定 |
| 配線 | リルート点（データ） | 入力をそのまま渡す小さな点。接続線の中央にカーソルを置いて、出る輪をクリックすると置けます |
