# 枝のパスを残してデータツリーを編集する

枝のパスは `{0;2}` のようなアドレス、その枝の各要素の番号は 0 始まりです。既存の **連結** や **間引きパターン** に加え、次の3つが使えます。

| ノード | 役割 |
|---|---|
| **指定番号を除く** | 枝の中で指定した番号だけを除き、残りの順序を保ちます。同じ番号は一度だけ除きます。折り返し 1 なら -1 は末尾。0 で範囲外を指定すると対象のパスを表示します。設定は同じパスの枝を優先し、設定に `{0}` しかない場合だけ全枝に共有します。 |
| **パスでツリーを合流** | 同じパスの値だけを A → B の順に連結し、違う枝や空の枝も残します。既存の **連結** と違い、一つの枝を別の枝へ自動で配りません。 |
| **パスで枝を取り出す** | 数値リスト `0, 2` は `{0;2}` を意味します。完全に一致する枝を1本取り出し、元のパスを保持します。空の枝は空のままで、存在しない枝はエラーになります。 |

## 試す

**開く** から [`examples/tree-branches.morph`](../examples/tree-branches.morph) を選びます。

1. 数列 10・20・30 と、その各値を枝分けしたツリーを **パスでツリーを合流** に入れます。結果は `{0}`、`{0;0}`、`{0;1}`、`{0;2}` の4枝です。
2. **パスで枝を取り出す** に `0, 2` を入力すると、`{0;2}` の `30` だけを元のパスのまま取得します。
3. 別の配線では **指定番号を除く** が中央の位置 20 を除き、台座が X=10 と X=30 に残ります。
4. インスペクターまたは **値を見る** では32行ごとにページを切り替えられます。**枝を1本だけ表示** で絞り込めます。閲覧はプロジェクトに記録されません。

[Grasshopper のリスト公開解説](https://developer.rhino3d.com/guides/grasshopper/gh-algorithms-and-data-structures/data-structures/) と [ツリー公開解説](https://developer.rhino3d.com/guides/grasshopper/gh-algorithms-and-data-structures/advanced-data-structures/) を参考にした独立実装です。Rhino 本体、Grasshopper のファイル、プラグインとの互換機能ではありません。
