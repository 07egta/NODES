# 編集できる作品例

アプリ上部の「作品例」から、名前と説明を見ながら同じ作品を開けます。このフォルダーの`.morph`を「開く」から選んでも編集できます。

| ファイル | 作品 | 注目する設定 |
|---|---|---|
| `01.morph` | ねじれの花器 | 半径、高さ、凹凸、ねじり角 |
| `02.morph` | 光のリング | 球の大きさ、移動量、円形配列の個数 |
| `03.morph` | 星のトーテム | 星の頂点数、押し出しの高さ、ねじり |
| `04.morph` | 螺旋のスケッチ | 半径、巻数、高さ |
| `05.morph` | 波打つブロック | 配列の間隔と個数、波の振幅 |
| `06.morph` | 輪郭からロフト | 円の半径を作る数列、高さを作る数列 |
| `07.morph` | サイン波の塔 | 範囲の個数、三角関数の振幅・周波数・位相、円柱の寸法 |
| `08.morph` | べき乗の山脈 | 範囲、べき乗の指数、円錐の分割数（4で四角錐）、ミラーの軸 |
| `09.morph` | ノイズの花器（厚みつき） | 半径の式、グラフの縦・周の分割、ノイズの振幅と模様の大きさ、ねじり角、厚み（張り出しチェックの結果は「データを見る」で確認） |
| `10.morph` | 引力点のパターン | ランダムな点の個数とシード、引力点の位置、再マップの最小・最大（近いほど高い柱） |
| `11.morph` | パイプのらせんランプ | らせんの高さ・半径・巻き数・分割数、管の半径と周の分割、端を閉じるか |
| `12.morph` | ジャイロイドの小物入れ | 箱の寸法、単位の大きさ、壁の太さ、分解能、なめらかにする回数 |
| `13.morph` | シンプル花瓶→らせんGコード | 花器の寸法、温度、底の層数、層の高さ（Bambu A1 mini 向け・実機未検証） |
| `14.morph` | 波模様の粘土の器 | 波の振幅・波長・ねじり、層の高さ（TRONXY Moore 1 向け・実機未検証） |

同じ番号のSTLは初期値で生成した形状です。`04`は曲線のみのためSTLを含めません。`07`〜`12`は手で書いた`.morph`で、STLはまだ生成していません（`NODES --export-demos examples`で、`.morph`とSTLをまとめて作り直せます）。`07`〜`12`はコンパイル・実行による確認が済んでいません。STLの単位は読み込む側でmmに設定してください。

元の作品例を残すには、編集後の`.morph`を別名で保存してください。

## 精密曲線の作例（追加、CI未確認）

`curves/11-circle-divisions.morph` 〜 `curves/16-trim-loft.morph` を「開く」から読み込めます。円の等弧長分割、らせんの局所断面軸、家具の補間輪郭、折れ線オフセット、直線交点、部分曲線のメッシュロフトを扱います。断面軸は現行の単一出力・点型によるXYZであり、独立したPlane型はまだありません。これらはビルド・実行未確認で、CIに保存再読込み試験を追加しています。
