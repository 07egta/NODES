# 編集できる作品例

アプリ上部の「作品例」から、名前と説明を見ながら同じ作品を開けます。このフォルダーの`.morph`を「開く」から選んでも編集できます。

| ファイル | 作品 | 注目する設定 |
|---|---|---|
| `01.morph` | ねじれの花器 | 半径、高さ、凹凸、ねじり角 |
| `02.morph` | 光のリング | 球の大きさ、移動量、円形配列の個数 |
| `03.morph` | 星のトーテム | 星の頂点数、押し出しの高さ、ねじり |
| `04.morph` | 螺旋のスケッチ | 半径、巻数、高さ |
| `05.morph` | 波打つブロック | 配列の間隔と個数、波の振幅 |
| `06.morph` | 輪郭からロフト | 円の半径を作る数列、高さを作る数列 |
| `07.morph` | サイン波の塔 | 範囲の個数、三角関数の振幅・周波数・位相、円柱の寸法 |
| `08.morph` | べき乗の山脈 | 範囲、べき乗の指数、円錐の分割数（4で四角錐）、ミラーの軸 |
| `09.morph` | ノイズの花器（厚みつき） | 半径の式、グラフの縦・周の分割、ノイズの振幅と模様の大きさ、ねじり角、厚み（張り出しチェックの結果は「データを見る」で確認） |
| `10.morph` | 引力点のパターン | ランダムな点の個数とシード、引力点の位置、再マップの最小・最大（近いほど高い柱） |

同じ番号のSTLは初期値で生成した形状です。`04`は曲線のみのためSTLを含めません。`07`〜`10`は手で書いた`.morph`で、STLはまだ生成していません（`Morphlet --export-demos examples`で、`.morph`とSTLをまとめて作り直せます）。`07`〜`10`はコンパイル・実行による確認が済んでいません。STLの単位は読み込む側でmmに設定してください。

元の作品例を残すには、編集後の`.morph`を別名で保存してください。

追加機能に対応したソース版では [`tree-branches.morph`](tree-branches.morph) で、枝のパスを保った合流・抽出、指定番号の削除と配置を確認できます。

[`curve-basics.morph`](curve-basics.morph) では直線・折れ線・長さ・曲線の等分割を確認できます。

### 懸垂線：糸やケーブルのたるみ

[`catenary-cable.morph`](catenary-cable.morph) を開くと、24 mm 離れた両端に
約 30.189 mm の糸を掛けた形を確認できます。「ひもの形」ノードの長さを増やすと
たるみが深くなります。長さは両端の直線距離より大きくしてください。
重力は既定で −Z です。X・Y・Z で任意方向を指定できますが、ゼロベクトルや
両端が重力方向に並ぶ場合は作れません。出力は端点を厳密に通る開いた折れ線
（4〜1024 分割）です。測った折れ線長は指定した連続曲線の長さより少し短くなります。
形状や荷重に関する構造計算ではありません。

操作上の参考: [McNeel Rhino 8 の Catenary](https://docs.mcneel.com/rhino/8/help/en-us/commands/catenary.htm)、
[Grasshopper 2 の Catenary From Length](https://www.rhino3d.com/docs/grasshopper2/specs/00000000a9c64cb18f0850a66f112603.html)。
本ノードは独立実装で、出力は曲線 1 本です。NURBS や別の頂点出力はありません。
