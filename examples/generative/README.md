# 生成デザインの編集可能な作例

NODES の「開く」で `.morph` を選択してください。既存のテンプレート10作品とは別です。出力は静的なSTLではなくノードグラフです。CIの評価が最初の実機コンパイル確認になります。

| ファイル | 作品 | 変更できる設定 / 制限 |
|---|---|---|
| `01-twisted-tower.morph` | ねじれの塔 | 高さ・ねじり角・上端倍率。閉じたメッシュの形態スタディ。 |
| `02-voronoi-lamp.morph` | ボロノイランプ（線のスタディ） | 点数・シード・半径。線形状のみ、ランプの厚みや接合は未実装。 |
| `03-wave-facade.morph` | 波打つパネルファサード | セル倍率・振幅・波長。離れたパネルの形態スタディ。 |
| `04-slat-chair.morph` | スラット椅子の構成スタディ | 板の幅・個数・座面高さ。強度・接合や人体寸法の検証は対象外。 |
| `05-spiral-stair.morph` | らせん階段 | 角度・高さの2数列の個数を揃えて調整。構造安全性は未評価。 |
| `06-honeycomb.morph` | ハニカムパネル | 半径・行列数・間隔。独立した六角タイルで、蜂の巣状の連続壁ではない。 |
| `07-organic-sculpture.morph` | 有機的な彫刻 | ノイズのシード・模様の大きさ・せん断。自己交差は未検証。 |
| `08-fractal-tree.morph` | フラクタルツリー | 深さ・角度・縮小率。折れ線の枝で、体積はない。 |
| `09-density-wall.morph` | 密度が変化する壁 | シード・引力点。格子数を変えたら乱数の個数も nx×ny に変更。 |
| `10-surface-lattice.morph` | 円筒に沿う三角格子 | 曲面の半径・展開長さ・セルの大きさ。円筒限定、汎用NURBS曲面ではない。 |
